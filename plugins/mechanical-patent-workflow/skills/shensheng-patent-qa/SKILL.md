# 申晟专利独立质检

用户已要求：以后案子写完，默认通过独立入口，使用 `patent-draft-review` 做质检。首次成稿和改稿均在实际文件生成后、最终交付前进入；用户当次明确限定范围时按其要求执行。

## 先读取

- [公开专利审稿技能](../patent-draft-review/SKILL.md)及其要求的审稿、因果、图文与报告参考；使用随包独立公开方法，本入口负责申晟工作流接入。
- 名称与标号核对必读[部件名称与标号逐处核对](references/component-occurrences.md)，逐次建立位置清单，并用[逐处扫描脚本](scripts/audit_component_occurrences.py)辅助核查。
- 机械结构案另读[机械撰写风格](../mechanical-patent-drawings/references/shensheng-drafting-style.md)、[逐段图文覆盖及逐根引线验收](../mechanical-patent-drawings/references/cad-figures.md)。真实修订另读[专利文稿与真实修订](../mechanical-patent-drawings/references/drafting-and-review.md)。
- 引线长短和线形以机械附图技能的最新用户认可样例核对，当前为[图8标记41](../mechanical-patent-drawings/references/approved-leader-fig8-41.pdf)：纸面约6.3mm、两段反向弯曲的紧凑顺滑短S。普通引线及主要箭头的S主体均据此起排；不能继续用旧整套统计的中位数或11.55mm最短值验收。确须延长的逐处记录原因，同时核查真实落点及净距。

随包patent-draft-review为独立公开兼容入口，非第三方上游原包；原上游组件未随包分发，需使用者另行合法取得。随包公开报告生成器仅需Python标准库，使用目标机器可用的`python3`或对应Python 3命令；不依赖原机器虚拟环境。若实际环境不可运行，先交同字段Markdown并说明限制。

默认仅做稿内质检，复用已完成且对应本版本的检索材料；不因上游包含检索流程而重复启动外部检索或向其他平台发送稿件。原撰写流程已要求的实际专利检索继续由该流程完成，质检读取其证据及未核事项。用户指定 Work Buddy、DeepSeek 或其他复核平台时再按其要求追加，本入口不依赖这些平台。

## 冻结文件并独立审阅

1. 确认当前有效版本、申请类型、程序阶段及本轮修改范围，列出实际 Word、正文、独立附图 PDF／原图、交底和必要模型的路径及摘要值。优先接收用户指定的文件，不要求用户为质检重新制作本技能格式的目录。交底无正式权项时按技术方案检查，不编造权项；外观或仅附图任务只核适用的形式与图面，说明功能因果为何不适用。
2. 默认另启未参与本轮起草的独立子代理，给冻结文件路径、原始技术依据、审核范围和上述技能路径。要求它实际读取文件、渲染看图并返回证据，不给起草者“已通过”的自评或预设结论；必要的用户确认事实保留来源标识。审阅者只出意见，起草者负责核实和整改。
3. 无独立执行条件时完成能做的本地复核并明确标记“独立质检未完成”，不把起草者自检冒充独立审阅。已取得但未实际查看的附图记为未核读，不能以 OCR、图片数量或标号集合代替目视。

## 用户要求与保护层次验收

独权必须上位、简洁、抽象，正式稿同一特征只用一个名称；撰写与审核共用[独权保护层次与特征名称](../patent-disclosure-skill/skills/patent-application/references/claim-scope-and-names.md)。将**保护层次**作为单独必核项：先还原总体技术构思，再逐限定判断是否把可下沉的多组实现或全部检索区别捆入独权。只换上位词、只减字数、只证明支持或标号正确，都不能判通过；必要协同也不为简短而删掉。

正式稿的特征名称、标记表及各栏目必须一致，不允许“上位名（另一特征名）”或同号交替命名。历史别名只用于输入识别和追溯；按部件核对参考启用最终稿规范名称检查并人工核未知名，不能因同号把别名放过。正常数字括号、形态描述及文献原文引用分别处理。

机械稿另将**特征引入与归属**单独验收：按[共同细则](../patent-disclosure-skill/skills/patent-application/references/claim-scope-and-names.md#新特征先交代归属和设置关系)，沿首次引入句、已引入母件或真实引用链、所属/位置/连接及后续展开核实际文字，并在现有审核记录定位原句及整改。名称或编号出现过、图例已列、平行从权已介绍及机检通过，均不能替代此项；同句清楚引入可接受，不要求把全部实施例组成上提独权。

配对支路、部分量词、方向回指、外部配合对象及删除标记联动按[共同细则](../patent-disclosure-skill/skills/patent-application/references/claim-scope-and-names.md#配对关系量词与配合对象)逐处核原文和依据。不能以句子更短认定范围未变，也不能只撤某幅图的数字便关闭全套同步问题。

上游审稿的保守、平衡或收窄备选服务于实际范围决策，不要求机械凑档；用户已明确上位方向时，不以备选模板把非必要细节重新塞回。保留原始记载、申请阶段与风险边界，确有不能自行决定的实质取舍再说明。上位后同时核主方案、摘要、术语表及结尾，防止旧实例表述反向限定主权。

审阅者先从用户指令、认可范文和原始材料独立核对本案要求及来源，再核实际稿件；不能从成稿或起草者的“通过”结论推定标准。机械独权按[本案要求与保护层次底稿](../mechanical-patent-drawings/references/shensheng-drafting-style.md#本案要求与保护层次底稿)逐限定判断保留、上位、下沉或删除，检查替代结构和说明书支持。只证明材料存在、技术作用清楚或属于检索区别，不足以证明该具体限定有必要。报告必须能定位到实际限定及判断，不能只写“已核必要特征”。

分栏标号检查先审配置与来源，再审实际Word和PDF；按[配置与错误样本复验](references/component-occurrences.md#配置与错误样本复验)确认故意错误可被检出。格式机检不证明权项已充分上位，专业判断也不替代最终格式检查。技术支持、保护层次、标号格式和图面分别记已核通过、待整改、未核或不适用，并有证据或理由。缺少本轮实际判断的项目继续完成，不能以其他项通过概括为整稿合格。

## 五类检查

| 类别 | 实际检查与证据 |
| --- | --- |
| 方案逻辑 | 沿问题及原因、组成／步骤、连接／传递、动作条件和效果还原作用链；检查状态切换、边界及异常工况、相互矛盾和缺少中间环节。区分原文事实、工程推断与待验证假设。 |
| 公开充分性风险 | 查关键构造、配合、动作顺序及必要条件是否有据可实施，概括分支是否有对应教导；指出缺哪项信息、影响哪个方案及应补什么证据。不能把没有尺寸、没有测试或写得简短直接等同于公开不充分，也不擅自补造结构。法律定性核实适用的官方依据。 |
| 形式与支持 | 逐项核真实引用路径和累计限定、先行基础、术语及标号、说明书支持、正式栏目、摘要、图号及首次引用顺序。按机械撰写风格检查权利要求1是否有可概括的具体形式、可下沉的实施细节或重复表述。有指定或已确认模板时，将实际 Word 和 PDF 与母版对应部分核对分节、样式、页眉页脚、图号和页码。既有机检只作辅助。 |
| 标记落点 | 逐图、逐次出现、逐根辨认引线结构端或箭尖，核对所指实体、孔槽或配合面、正文定义、同号跨图归属、装配及遮挡状态。有模型时回看同源几何；只有距离接近某条线不算确认了目标部件。 |
| 引线与图面 | 在最终页逐根放大看曲线全长、整箭、线尾到数字的间隙和完整字框。与相邻引线、轮廓、剖线及装配虚线核对交叉、压线、贴行和真实净距，记录各处处理结果。剖视图另按下述断面线保真要求核对。再按最终图幅看 S 形、线宽字号和标号能否清楚辨认。美观标准单列。 |

机械图面以同一标号在某张图中的一次出现为一行，至少记录图号／页码、标号、目标部位、实际落点依据、引线及邻线检查结果、关联意见号。缺少清晰图或模型依据时写具体未核位置。

剖视图及局部剖视按[剖视图标引与断面线保真](../mechanical-patent-drawings/references/cad-figures.md#剖视图标引与断面线保真)逐根核查：数字完整字框须在真实剖切材料区外，大板边缘排线后中央未排线区仍按材料判断；优先从真实孔腔或开口侧出线，必要延长短S逐根说明。必须穿越其他剖切实体时允许与完整连续断面线清楚交叉，禁止用白底、擦白、mask或剪段让断面线让路；孔腔及断裂处只依真实几何边界裁止。接收布标前的无标注原始 hatch 或同源线稿，与最终 Word、独立 PDF 的实际渲染逐段对看，分别记录“字框在材料区外”和“原始断面线连续保留”的依据及结果；仅检查数字未碰斜线、或仅看成品无交叉均不足以判通过。缺原始依据时记具体未核范围，不把程序检查替代目视。

图面结论按落点真实性、完整字框净距、整箭与全引线、互遮挡、自遮挡、剖切材料区与原始断面线、最终 Word/PDF 分项记录“已核通过、待整改、未核、不适用”，并附证据或不适用原因。一个端点正确、无字符冲突、模型有效或零件零交集，均不能推出其他项已通过。手动覆盖布局坐标或改变字体、比例、视角及几何后，按最终全图重新筛查并看成品；可使用[布局冲突预筛](../mechanical-patent-drawings/references/layout-preflight.md)，但无预警不得冒称完整质检通过。

## 名称与标号逐处验收

- 依据核定术语表建立唯一正式名称—标号对照，另登记历史名称和简称用于识别残留，不允许在正式稿交替使用。对权项、主方案、具体实施方式、摘要及图名/标记表中每次出现按相应栏目逐处核查，保留位置、上下文、实有标号、名称状态及依据。其他位置已有正确名称或标号，不能替代当前这一处的检查。
- 先登记各栏目核定的标号格式，再处理漏号、错号、同名异物、同物异名、并列省略和代词。省号栏目及确实不同的对象逐段或逐处写明依据。词面嵌套、别名和同名不同零件须人工判定，不能对同名词整篇豁免或直接批量补号。
- 实用新型说明书“实用新型内容”章节依共同细则不带部件附图标记，配置`forbidden`并查残留，正式名称检查保持开启；具体实施方式等按其核定规则核号。不能因本章省号而跳过名称，或误删图号和技术数值。
- 完整审稿覆盖全部权项、正文、标记表和本轮全部附图。改后对实际交付副本重跑适用的全稿名称标号扫描；人工核读按下节对差异及关联范围复核，未变部分满足条件时复用原完整记录，并目视修改页及对应图面。报告登记实际覆盖、每处异常的处理和未核原因；只有集合匹配、局部抽查或语义通读时不得声称全稿逐处完成。

## 集中审阅与差异复核

- 首轮对实际文件完整独立审阅。集中核实一批意见、同步整改后，再生成受影响的 Word／PDF，避免每条意见都重建全套；沿用现有问题记录，不新增报告或审批。
- 后续复核差异及关联引用链、同号跨图和邻近引线；字体、视角、比例或几何改变时，对该图最终全图筛查并目视。未变部分仅在原始依据、规则及样式、范围、阶段和模板仍适用且有原记录时复用。用户指出漏检时，对应及同类旧通过失效。
- 核心权项变化由独立审阅者重查，并交回撰写流程对受影响特征和组合补检；不能据初步检索或文件摘要免除适用核读。
- 同时交付交底与申请时，可在同一审阅任务中分别核读两份实际成品并记录范围、依据与结论，共同技术底稿不替代各自质检。所有实际交付副本仍须渲染、隐私清理和清理后复验。

## 整改及复核

- 每条意见有稳定编号、严重程度、文件及页／项／段／图位置、原文或图像证据、影响、建议和处理状态。先核实再采纳，误报写驳回依据；材料缺口列待确认，不为关单补造事实。
- 对已授权且有依据的错误直接整改并同步正文、权项、摘要、标记表、合册／分册 Word 和独立图 PDF。已核定范围或仅局部改稿，保持本轮授权边界；需用户选择的实质方案另列，不自行替用户决定。
- 复核更新后的实际成品，逐条关闭意见，并连查受影响的引用路径、图页、同号其他视图和相邻引线。影响方案或核心权项的改动由独立审阅者重查。复用既有意见须同时确认交付文件内容、原始依据／模型、适用规则及样式版本、审核范围、程序阶段和模板均未变化且已有完整记录；记录相应摘要值或明确版本。仅变化部分重查，其余复用。文件摘要未变但规则、依据或范围改变时，旧通过不能自动沿用。
- 用户指出漏检时，对应旧“通过”结论失效；在本轮授权范围内重核该要求及同类问题。文件哈希相同只能证明内容未改，不能证明原判定正确；不得以字节一致继续复用已被质疑的合格结论。
- 不因反复改写就认定缺证据问题已解决。缺事实或连续复核无新增依据时，完成其余可做工作，明确剩余问题及影响；案卷沿用既有轮次规则，不由质检另造无限循环或额外轮次。

- 用户再次报告同类问题时，在本轮获准范围内重查整套同类风险和相关姿态，不能只复查曾经通过的一个落点。已确认的字框压线、整箭盖线或残留错乱线必须整改后重看最终交付页；“沿用原路径”“内部特征外引”或已经写明理由不能豁免完整字框、整箭及长段贴行。引线本身确需横交少量轮廓时，按机械附图规则逐处核实清楚交角和断面线保真。
- 已有自遮挡、互遮挡或小特征歧义的诊断未闭环时，该图面项保持待整改或未核，不能用模型有效性、无实体交集、脚本完成或报告生成覆盖残留问题。修正完成后重新冻结实际 Word、PDF及相关底图并核其摘要；必要的已知问题未解决不发布“已全部修复”的结论。

## 报告与交付

默认在当前工作区 `outputs/patent-qa/{案名}_{时间戳}/` 保存内部审核数据、逐图逐根记录、整改复核记录和离线 HTML 专利审核报告；无法生成 HTML 时按公开兼容报告约定字段交 Markdown，说明限制。使用同包公开兼容 `../patent-draft-review/scripts/render_review.py`，报告生成与技术判断、目视核图、问题整改分别记状态。未执行新检索时登记独权和实际未执行范围，不伪造新颖性或创造性结论。

记录所审文件及复核文件的摘要值，使报告对应实际交付版本。报告交付说明已核范围、未核项及关键遗留问题；不能用“报告已生成”代替“问题已解决”。案卷只读取并归集已有质检结果，不重复启动审核。

机械案问题分诊及正式定稿／阶段成果状态沿用[共用收尾](../mechanical-patent-drawings/references/drafting-and-review.md#共用收尾)。已确定可修的错引、错号及形式错误先整改；关键事实、文件、检索或独立核读未完成时明确范围，不以列清单代替验收完成。脚本误报须核实并记录驳回依据，不为通过工具而修改正确的技术文字。

最终交付副本产生后执行用户 AGENTS 的隐私清理并重新核验可打开、内容及图页完整：Word／PDF／HTML 及打包副本均清除不属于交付内容的身份、工具、时间和内部路径等元数据；需要真实修订或批注时保留其功能并匿名化身份。清洁正文清除附带修订、批注和版本历史。清理后复查实际交付件的图文与版式，保存最终摘要值及结果；内部日志与审核源数据不混入交付包。

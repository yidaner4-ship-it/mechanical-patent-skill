# PatSeek 外部服务适配入口

本目录仅含本项目原创适配器，不是 PatSeek 原技能或官方客户端。原第三方客户端、依赖、账号、API Key、积分及再分发许可均不随包。服务来源参见 [PatSeek](https://patseek.cn)；安装者应向服务方核实其现行客户端、费用、接口和使用条件。本包不保证服务可用或某次查询不收费。

先读 [INSTALL.md](INSTALL.md)，由用户自行合法取得兼容客户端，放在插件缓存以外的持久 `vendor/patseek/`，显式设置 `PATSEEK_VENDOR_ROOT` 和 `PATSEEK_CLIENT_PATH`。受信根与文件须通过路径、所有者、写权限和非符号链接检查；插件不携带用户的路径、客户端或授权。未设置根变量时兼容本技能本地 `vendor/`，但该旧位置会被插件更新替换。适配器不会下载、安装、开户、充值、购费或把失败查询静默转给其他网站。

实际查询从随包 `shensheng-patent-workbench` 的安全包装器进入。不得直接执行本适配器付费查询，或在系统命令参数中放入 API Key、原始检索式、完整技术稿件。包装器负责凭据、案件授权、查询输入及预算控制；适配器仅核验安全 hooks 已注入，在当前进程内加载用户客户端，把参数和 no-store hooks 传入，最后清空运行期 API_KEY。适配器自身不启动子进程，不把检索式复制到新进程 argv。

缺少路径、权限不可信、接口不兼容或没有包装器上下文时明确失败。标准输出和错误中的当前 Key 按文本流遮蔽；适配器不能把不可信第三方代码变为沙箱，也不能保证第三方程序没有其他隐式网络或存储行为。只使用用户已核验并获许可的客户端，确认其导入阶段无查询、副作用及独立存储路径。不得把“入口启动”或零条结果当作检索完成。

PatSeek 不可用时仍可使用本包 `patent-search` 的 CNIPA 免费检索流程；应明确选择并记录不同数据源及覆盖范围，不在本适配器中自动切换。任何外部平台提交都遵循当次用户授权。

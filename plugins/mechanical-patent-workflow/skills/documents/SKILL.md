# Word 文档辅助

这是**独立公开辅助版本，并非官方缓存包**。说明与脚本按本工具包的通用功能需求独立实现；不包含官方 Documents 技能、专有运行时、客户资料、应用程序或字体。新代码以仓库 MIT 许可发布，版权归 `2026 Mechanical Patent Toolkit contributors`。Python 脚本只用标准库。LibreOffice、Poppler、Word 由使用者另行准备并遵守各自许可；工具不联网、不下载软件、不安装应用。

## 制作原则

1. 先检查用户给定的母版、既有稿、附图、交底和修改范围。以母版的页面尺寸、分节、字体、段落、页眉页脚和编号为准；另存新目录，保持源文件可追溯。母版缺失时明确标注采用的临时格式，不能称为用户已确认版式。
2. 技术事实以材料和用户确认内容为依据。独权只保留必要结构及配合关系；权1以简洁、清楚为先。不能为使文稿“完整”而补造结构、尺寸或技术效果。撰写和技术质检转交本工具包相应专利技能。
3. 说明书附图采用独立视图一图一页、完整墨迹居中、图号在页脚居中；按首次实质引用顺序连续编号。短 S 形引线及其参数、真实落点和避让规则统一引用 `mechanical-patent-drawings`，不要在本技能中另定数值。已冻结图必须核对实际嵌图及最终页面。
4. 以正式段落、分节和实际嵌入图片实现版式。检查孤行、跨页标题、表格断行、图中文字清晰度与页眉页脚；不能用空行和重复图片抬头掩盖分节问题。

## 真实 OOXML 修订

用户要求“真实修订”时，使用 Word 修订或正确的 OOXML `w:ins`、`w:del`、属性修订等结构；高亮、红字、批注及一份修改说明均不能替代真实修订。保留原文与修改结果的对应关系。用户未要求修订交付时，交付已接受修改的洁净稿。

修订稿至少验证两种视图：显示修订的版本和接受全部修订后的版本。核对接受后的正文、权项、附图、交叉引用和页码与核定稿一致；比较渲染页面，记录实际查看的页数。LibreOffice 与 Word 的修订显示行为可能不同，无法验证某种视图时如实记录，不声称验收完成。

`scripts/privacy_scrub.py` 可保留并匿名化既有修订，不能生成真实修订。它仅支持自动接受常见的文字插入、删除、移动及属性修订；遇到段落标记、行或单元格等结构修订会拒绝输出。此时先在 Word 中正确接受并核对，再清理独立副本。不要绕过此保护。

## 本地渲染

从本技能目录执行，路径均为示例相对路径：

```bash
python render_docx.py draft.docx --output-dir qa-render
python render_docx.py draft.docx --output-dir qa-render-2 --libreoffice /path/to/soffice --pdftoppm /path/to/pdftoppm --dpi 150
```

脚本优先使用显式可执行路径，其次查找 PATH，并识别常见 macOS、Windows 安装位置。Windows 上可显式传入 `soffice.exe` 和 `pdftoppm.exe`；Linux 通常通过 PATH 发现。需已安装应用和匹配字体；如缺失，报告依赖缺口。它创建临时转换副本和独立 LibreOffice 配置，输出 `document.pdf`、逐页 PNG 和不含源路径的 `render.json`，拒绝覆盖非空结果目录。

渲染结果只是供核对的中间件，`visual_review` 和 `privacy_review` 固定为 `pending`。逐页目视 PNG，并在可用时核对 Word 原生页面：是否漏页、缺字、图文遮挡、断行变化、附图错页、字体替换及修订显示异常。出现问题后修改文稿，重新渲染受影响部分及关联页。PDF 导出后的元数据需另按 `pdf` 技能清理，渲染器本身不保证交付隐私。

## 交付副本隐私清理

```bash
python scripts/privacy_scrub.py reviewed.docx clean.docx --revisions accept
python scripts/privacy_scrub.py reviewed.docx anonymized-redline.docx --revisions preserve
```

必须显式选择修订策略。脚本拒绝覆盖源文件或已有目标；清除可选文档属性、核心/扩展/自定义属性、缩略图、评论及作者关联部件、编辑会话标识、文档变量、模板关联和本地文件超链接。保留修订时将作者改为 `Anonymous`，移除修订时间；保留正文中有意的署名、申请信息、页眉页脚以及技术内容。清除自定义 XML 数据绑定时保留已显示的内容。

**本脚本始终移除批注**，`--revisions preserve`只表示保留文字修订。用户要求交付批注时不要用本脚本处理该副本，应在Word中保留批注内容、匿名化身份并逐项复查；不能把保留修订误解为保留批注。

脚本拒绝处理数字签名、宏、嵌入包、外部格式片段（altChunk），以及包含本地源路径的域或需人工处理的链接对象。先制作独立无签名导出件，或在 Word 中解除链接、移除不属交付内容的源对象并检查结果后重试。不能把失败的脚本输出或手工改扩展名当作清理完成。

脚本是限定范围的包级清理工具，**不能证明所有隐私已消除**。在 Word 中执行“文件 → 信息 → 检查问题 → 检查文档”，按用户隐私清理范围复查隐藏文字、不可见内容、嵌入图片元数据、外部对象、账号或个人标识等。正文有意保留的信息按用户要求处理。清理后重新打开、渲染并逐页核对；批注或真实修订的内容和状态仅在用户明确要求时保留并匿名化。

对 PDF 导出件、分册、交付目录复制件及 ZIP 内副本同步清理和核验。报告应区分：脚本实际完成的包级检查、Word 检查器的实际执行结果、实际目视页面，以及尚未完成的事项。不得由成功退出码推定技术、版式或附图引线合格。

# 审稿方法与证据

以所审文件的具体位置为起点，逐项问：此处定义什么对象；它和哪个对象怎样连接、传递或约束；在什么状态下产生什么效果；材料为这条关系提供了什么依据。把材料事实、用户确认、工程推断和待验证假设分别标识。

沿真实的权项引用链累加限定，回查说明书及附图能否支持其对象和范围。不要只比较关键词。对核心效果缺少的中间环节说明缺什么、影响哪里、需要何种材料；没有尺寸或试验本身不自动等同于不能实施。

机械结构结合实际安装基面、加工装配、紧固和工具空间、维护拆卸，以及本案适用的载荷、水、泥沙、腐蚀等工况判断。只适用于部分工况的结论须说明边界。几何接触不能作为水密试验结果。

正文逐段登记引图，图面按“某图中某标号的一次出现”记录。实际放大辨认结构端和数字端，结合上下文、同源模型及其他视图核实落点。冻结图只检查并登记，未经授权不改。最终嵌图和独立 PDF 均须看图。

每条问题须含可复核的位置、短引文或图像证据、影响、可行建议和状态。整改后核实际文件及受影响部分；未取得的新事实继续列待确认。报告生成、审阅、目视核图、整改和复核分别登记状态。

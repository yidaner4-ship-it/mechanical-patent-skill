# Excel检索表格辅助

这是依据通用表格功能独立编写的公开辅助入口，不是官方缓存技能或在线Excel控制器。数据、判断依据和报告要求由同包专利工作台提供。

## 使用与依赖

- 修改`.xlsx`候选表或对比表时使用，优先通过`openpyxl`操作用户指定母版的副本。依赖见`requirements.txt`；不要安装或复制办公软件、账号和商业运行时。
- 未提供材料不能编造候选、日期、命中数或检索结论。保留公开号、族、证据位置和实际来源，失败来源与真正零命中区分。
- 同一数据源生成Excel、Word及同版PDF；与工作台保持候选ID、技术特征、日期和判断状态一致。

## 制作与核验

1. 读取实际工作簿的sheet名称、表头、有效区域、合并单元格、已有公式和样式，确定需要修改的精确区域，不能以重建整表代替局部填写。
2. 保留母版行高列宽、数字格式、筛选、冻结窗格和打印范围；文字换行并调整必要行高，不使证据或长公开号被截断。样式从相应模板单元格复制。
3. 日期使用真实日期对象或明确统一的文本格式；公开号和带前导零标识按文本存储。事实、推断及未核状态分别记录。
4. 公式保持引用关系。`openpyxl`不会计算公式；需要最终计算结果时，使用本地可用的办公软件重算副本并重新读取验证。不能把缺失缓存值当成零，或宣称公式已经重算。
5. 复核新增行数、去重口径、关键字段、公式错误及打印页；有渲染条件时查看实际输出，有条件限制时说明未核范围。
6. 正式交付副本清理作者、最后保存者、公司、时间、自定义属性、批注、隐藏个人记录和无关嵌入对象；检查隐藏sheet、外部链接及名称定义，功能所需数据不得盲删。保留用户明确要求的审阅内容并匿名化身份。
7. 保存后重开，核对内容、公式及版式；不覆盖原始母版，不把内部日志或账号文件放入交付包。

## 输出

输出用户需要的`.xlsx`及实际核查说明；模板、脚本或文件成功保存不代表检索结论正确、技术评价通过或公式已计算。

# 面向制造与装配的 Fusion 精细建模

按整机功能和真实制造方式拆件，使每件自制件有可执行的工艺路线，每处安装有完整的定位、紧固和拆装关系。把关键细节实际建入模型，用最终保存的装配核对。

## 开始工作

- 读取用户指定的完整材料和当前有效模型，确认单位、版本、外形约束、使用工况及本轮修改范围。沿用已确认的结构和尺寸。对缺失尺寸作合理、可逆的工程拟定，并记录依据与影响；只有会实质改变方案且无法据材料判断的事项才询问。
- 将具体使用环境转化为设计条件：按本产品相关的水、泥沙/异物、温湿变化、腐蚀及安装基面等因素，识别失效路径，落实结构、材料和验证方法。承担防护功能的细节实际建入模型；改动后按[环境适配核查](references/verification.md#使用环境与防护)复核。
- 建模前列出[本案适用工况](references/verification.md#工况清单与覆盖)。新模型、局部改模和从专利资料派生的模型都按本技能检查，改模覆盖受影响的零件和工况。用户明确只要概念示意时按约定深度交付，注明模型用途。
- 区分用户确认事实、材料披露、采购图、工程拟定和待确认数据。按当前要求推进能够完成的设计。依当前案情处理冲突，并向用户说明采用的解释。
- 默认使用 Fusion 的独立组件、参数、特征和装配关系。通过可用的应用接口、Fusion API 或UI实施并观察结果。读取本机API定义或官方文档后使用方法，工具能力按实际环境确认。

## 依次落实

1. **先建立整机与零件清单。** 按整机、功能模块、零件和接口展开，覆盖外壳、内部机构、电机及减速器、风机、板卡、线束、管路、密封、支架和全部安装件。按本产品实际功能逐件确定自制或采购、材料、制造路线、数量、配合件和待确认事项。参考清单用于查漏，新增模块按用户方案和实际功能需求决定。
2. **按制造边界独立建模。** 每个独立制造或采购的零件建立可识别组件。重复同型件复用组件定义并建立独立实例，左右不同件分别定义。同一注塑件的一体筋、柱、扣随母件建模；独立弹片、嵌件和装入件分别建模。采购总成按真实外形与接口表达，所需内部细节按设计范围展开。
3. **将可制造性做进几何。** 塑件逐面考虑脱模、壁厚和侧抽，金属件逐特征落实车、铣、钻、磨、钣金或焊接等适用工序。逐件核对握持边、板管端口、孔槽入口、折弯和切削内角、胶件接触边，把该做的圆角、倒角、退刀、孔底和导入过渡建入实体。圆角和倒角按实际工艺、板厚和装配空间确定。承压、密封、定位或焊接配合需要保留直边时写明依据。弯管用连续相切的中心线表达真实弯曲及壁厚，焊接总成按制造子件和接头建模。详见[制造工艺](references/manufacturing.md)。
4. **把每个零件装得住。** 每个独立安装件都要有定位和保持方法，并具备承载、传矩或止退路径。螺钉、螺母、垫圈、销、卡环、嵌件、卡扣及胶焊连接按用途落实，核对配合侧。对接触式固定、运动关节及采购包络，反查实体中的保持结构、真实紧固件头型、工具入口及实际通过尺寸。螺纹可以按工况简化牙型，拆装核对真实小径、肩部和有效啮合。尤其逐个检查电机、风机、PCB、开关、传感器和接头的固定。详见[装配与机电接口](references/assembly.md)。
5. **按真实顺序装入和拆出。** 为子总成确定顺序、工具入口、插入方向及检修路径。预装状态与合壳后状态分别查。给活动件建立关节、自由度、限位及必要操作顺序。线束和软管需随运动保留弯曲、服务余量和防夹空间。
6. **以公差和工况检查配合。** 对轴孔、导轨、翻边、密封、插接、螺纹和扣合定义功能基准与关键尺寸链。名义装配通过后，继续核查关键公差极限、热胀和弹性工作状态，记录正间隙要求和设计配合量。
7. **逐件核查并修复干涉。** 检查所有交付实例的静态关系、全行程、装入和拆出过程，以及工具、插头和线束包络。对结果逐对定位原因、修改和复跑。目标是清除全部非预期实体侵入与净空不足；螺纹、压配、密封压缩及卡扣装配变形按具体配合设计另行验证并记录。详见[验证与交付](references/verification.md)。
8. **重开交付档复验。** 检查原生模型的可编辑性、实际关节、组件数量、零件独立性和关键尺寸。重新导入STEP对照尺度、实体、位置与接口。结合最终文件给出已核证据、拟定尺寸及剩余生产确认项。

## 交付要求

- 默认提供可编辑的原生总装、通用STEP总装，以及与本轮模型一致的零件/采购清单和精简制造装配核查记录。给出能从成品核对关键细节的局部视图或剖面。用户已有交付格式时按其要求。以交工厂加工或直接试制为目标时，把必要自制件制造图、关键尺寸与公差、材料工艺、标准件规格及装配要求纳入本轮交付。完整模具、CAM刀路、电气原理图和仿真随实际任务范围制作。
- 交付前执行[制造装配成品核查](references/verification.md#制造装配成品核查)，用重开的成品逐件对照实际工艺与安装关系。将仍是占位的零件、尚待选定的配合及未验证工况登记到实际版本，按证据说明完成度。
- 每件零件记录材料及工艺、自制/采购、安装与拆装、关键公差及检验状态。报告明示检查覆盖的构型、行程、算法与结果；对仍需供方、样件或试验确认的项目写清位置和影响。生产放行按实有证据说明。
- 改动关键结构后联查相关件、装配顺序、公差、干涉及原交付版本。用户授权修改的设计通过实际模型完成，文件的尺寸和状态与报告一致。
- 保存到用户指定目录并校验副本。交付前按[隐私清理](references/verification.md#隐私清理)处理原生模型、Word/PDF报告、导出件和压缩包内副本，重开确认内容与模型完整。

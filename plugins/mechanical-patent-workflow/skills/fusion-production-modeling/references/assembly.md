# 装配与机电接口

## 零件与组件

- 每件独立自制件及独立装入件建立组件并赋稳定零件编号、名称、材料、数量和版本。采购电机、减速器、轴承等可以作为采购总成，明确其采购边界和已核接口。未知内部构造按安装及运动包络处理，并在清单标明简化范围。
- 同一胶圈、弹簧或卡扣的自由态、安装态和变形态按同一零件的不同构型管理，BOM保留实际装机数量。
- 同型零件通过多个实例表达真实数量，检查实例路径、方向及上下文。需要单独制造的左右件、不同孔距件分别定义，整机BOM与实例清单一致。
- 注塑件的一体扣、筋、柱属于母件特征。独立金属扣、销、嵌件、螺钉、垫片与母件有各自实体和装配关系。焊接或胶合总成保留子件及连接工序。
- 每件都交代位置如何确定、哪个方向被约束、受力或转矩由哪里传出，以及拆卸前需要释放什么。检查悬空件、同轴但未止退的轴、无对边的螺钉以及两端都无法穿装的销。

## 螺钉、卡扣与支承

1. **螺钉连接。** 沿每枚螺钉检查入口、头部承压面、穿过件、通孔或沉孔、螺纹所在件及底部余量。需要独立螺母、垫圈、嵌件、隔套、锁紧件时实际加入模型。检查紧固后的夹紧长度、公差和反复拆卸条件。
2. **工具空间。** 对实际批头、套筒、内六角或扳手检查直径、工作长度、旋转角、插入和退出路径。工具与手位/工装空间按装配步骤核对。先装后封闭的连接明确其预装和维修顺序。
3. **壳体和盖。** 导片/导槽及止口负责何种定位，卡扣负责何种预定位或保持，螺钉和支承面承担何种载荷，逐项说明。核对开盖止挡、铰轴止退、根部载荷和检修释放。卡扣释放窗、工具及扣臂变形有空间。
4. **承力与传动。** 从电机反扭矩、轴向力、重量等追到机架或机壳。检查软壳螺柱、背板、隔套、轴承和止退件的受力关系。松配、轴承内外圈和滑套沿预定方向保持自由度。
5. **焊粘及磁保持。** 明确配对面、胶层/焊缝、工装和固化顺序，核查后工序和拆换。磁保持及摩擦保持的能力按实际计算/试验验证，开盖检测和机械联锁分别落实到结构。

## 内部机电零件

| 对象 | 模型必须核对的安装接口 |
| --- | --- |
| 电机、减速器 | 供应商外形、法兰/孔距、轴端、转矩支承、轴向保持、螺钉工具入口、出线、散热和拆换路径 |
| 风机与叶轮 | 固定框和紧固、进出口方向、叶轮包络、格栅净空、线端与检修；检查固定螺钉是否侵入叶轮 |
| PCB与重器件 | 板外形、安装孔、隔柱/嵌件/垫圈、板背焊点、元件高度及连接器插拔；板载器件依实际焊接或固定方式建模 |
| 开关和传感器 | 安装基准、固定件、检测对象、工作距离、触发行程、超行程与调节；核对移动件全程先后关系 |
| 接头和软管 | 两端型号、有效插入深度、密封、锁扣、卡箍、弯曲半径、拉拔方向、安装与清理入口 |
| 加热器及测温件 | 承托、夹紧、限温/测温件固定、热接触、隔热、端子防护及可拆路径，材料与温度工况有依据 |
| 线束 | 起终点、插头外形和防错插、线夹/护圈、穿孔、转角、服务余量、应力释放及随动包络 |

按照电气设计给定条件核对机械隔离和空间。电压、绝缘体系、环境与适用标准未知时记录待确认项并完成可据实设计的结构。

## 装配及维修过程

- 用现有零件列出可执行的装配顺序。每步检查零件、工具和夹具从开放空间到目标位置是否可达，核对后装件是否封住未完成连接。
- 分别验证正常操作、维护拆件和换件状态，例如关盖、先脱开再翻盖、取桶、抽盒、拔接头、退卡扣、取下PCB。对操作顺序中的保持、解锁和定位明确实物机制。
- 活动铰链上的线束和软管核对夹持点、柔性弯环、全行程弯曲和扭转、夹缝及相邻热源。图示静止曲线与全程包络分别验证。
- 爆炸图可解释拆件层级，装配可达性用实际装入/拆出路径验证。拆开后才能装的紧固件，在记录中明确并检查维修可复现性。

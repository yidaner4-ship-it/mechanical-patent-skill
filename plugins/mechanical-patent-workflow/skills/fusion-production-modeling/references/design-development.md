# 设计开发与实物核对

从方案设计开始，使功能要求、工程依据、可制造几何与最终实物逐步对应。精细程度以本案制造、安装、运动、使用和验收所需的信息判定；对功能无影响的几何简化登记范围，不用增加无用细节代替工程设计。

## 设计输入及对应依据

- 先确定设计对象及本轮阶段：从零设计、既定方案建模、局部改模或已有实物还原。用户已确认的结构、尺寸和约束沿用；发现冲突时追查依据，涉及核心方案且无法判断的事项才询问。
- 按产品适用性记录用途、使用者、安装空间与基面、外形限制、载荷、速度/行程、环境、寿命、操作维护、成本范围和制造数量。对关键要求写目标值或范围、来源、适用条件、验收方法与判据，不强迫无关指标入表。
- 资料状态区分确认事实、供方资料、计算结果、工程拟定和待验证。缺失信息可用有标记、可追溯的假设推进可逆设计；记录其影响，关键输入未经核实不标记为生产确认。
- 还原已有实物时先确认样件及型号/选项，安排必要测绘、拆解和接口测量，记录测量方法与精度、磨损及变形状态。照片可辅助外形核对，精密尺寸及隐藏结构须有相应依据。

## 原理、简洁基础方案与专利评审

沿运动、载荷、动力/能量、物料及密封路径建立功能关系，明确每项功能由哪些结构实现，先形成直接、可靠、可制造和可维护的基础方案。存在关键方案分歧时再做必要的方案比较，不规定必须增加多少机构或创新点。

涉及申请专利时，在关键结构定型前依[工程价值与专利性评审](../../patent-disclosure-skill/skills/patent-disclosure/references/engineering-value-and-patentability.md)开展查新及候选改进评审。逐项联系实际问题、区别结构及配合、作用机理、可验证效果与新增代价，执行删除、合并和常规替换检验。简化结构也可成为待检索的改进；普通必需零件按其实际功能保留，不要求逐件独立创新。检索空间不足或收益不足如实报告，不以无收益的结构、特殊尺寸或操作步骤勉强制造区别。检索与模型变化相互回查，不自动扩展成申请文件撰写或FTO任务。

## 计算、采购选型与总体布局

- 按适用需求完成必要计算或工程估算，例如运动关系、驱动力/扭矩与传动效率、承载与变形、稳定性、流量/压力、密封压紧或散热。记录输入、方法、载荷组合、材料及边界条件和结果，用其确定规格、截面和关键尺寸；估算和仿真的结论限于实际依据，关键承载件不只凭外观比例定尺寸。
- 关键采购件落实制造商、具体型号、选配项、图纸/CAD版本及来源日期。核对性能曲线和适用条件，并依据实际配置检查安装孔、轴端、接头、出线及检修空间；有必要时由供方图纸或采购实件复核关键接口。
- 待选型包络可用于初步布局，受其影响的孔位、支架及接口保持待确认。完成选型后替换并复核关联件，不将外形相近的不同配置混用。
- 先布置主要机构和采购件，确定整机/子总成基准、关键接口、运动范围、线管路径、操作及装配维修空间，再细化外壳和局部结构。关键接口和尺寸链随参数关联，变更后联查依赖件。

## 制造尺寸及状态

- 以零件成品的功能尺寸管理总装。毛坯加工余量、铸造/注塑收缩补偿及工装尺寸在相应制造模型或记录中单独管理，明确基准和换算关系，不把制造补偿混入成品总装而改变功能接口。
- 逐件落实独立制造/采购边界、工艺及真实安装。材料、热处理、表面处理、粗糙度及不能仅靠几何表达的要求，按适用性写入同版图纸或技术要求。
- 对密封、弹片、卡扣、软管等区分自由态、安装态和必要工作态。自由态用于其制造要求，安装/工作态用于相应接触、压缩、变形和净空核查；标明状态和转换依据，避免以任意刚体穿透代替弹性验证。
- 关键配合建立功能基准、公差和尺寸链，核查极限组合及适用的温度、弹性变形和表面处理影响。材料与工艺选择、尺寸和检查结论相互一致。

## 阶段完成条件

下表用于本案计划和自检，可合并到现有记录；已完成的阶段复用有效证据，局部改模只复查受影响范围。

| 阶段 | 适用的完成条件 |
| --- | --- |
| 需求与基础方案 | 关键指标有依据与验收方法，功能及工作路径可解释，缺口已标记 |
| 查新及候选改进（专利用途） | 有可追溯检索依据、区别与效果链条，新增复杂度完成必要性/代价评审，未确定事项如实记录 |
| 关键计算与选型 | 关键参数由计算或可靠资料支持，采购配置明确，假设与受影响接口可追踪 |
| 总体布局与接口 | 基准和功能路径明确，运行、操作、装配及维护空间可核查 |
| 零件与制造设计 | 工艺、材料、实体特征和真实连接已落实，关键公差及状态表达明确 |
| 验证与出图 | 按[验证与交付](verification.md)完成适用检查，问题整改并复核，模型/图纸/BOM同版，交付档重开与STEP复验 |
| 样机核对 | 同版实物测量、试装及适用工况运行有记录，差异已归因、处理并复验 |

自检通过后继续推进，不为例行阶段重复请求批准。查资料、计算或改模可闭合的问题主动完成；需要实际测量或试验的缺口保留实际状态，明确所需数据和验证方法。上游关键条件未满足时，不用下游细节完成度宣称整体通过。

## 样机与模型一致性

- 一致性至少按本案相关的零件种类及数量、材料/工艺、关键几何与公差、接口规格、连接保持、装配位置、运动及工作状态逐项核对。尺寸判定按已定义公差，不要求制造偏差逐点为零。
- 试制前保留作为依据的模型、制造图、BOM和技术要求版本。取得采购实件及样机后，核对关键尺寸、实际装配顺序和工具可达、全行程、负载运行及维护等适用项目。
- 对差异区分设计失误、加工超差、采购配置变化、装配偏差及资料/测量问题。先归因再处理：设计问题修订关联模型及图纸，合格设计被加工超差偏离时处理超差，不将制造错误直接改成设计要求。经确认的设计变更同步到BOM和验收条件，并复核相关件及工况。
- 关键要求记录判据、验证方法、输入、结果和版本。几何检查、计算/仿真、供方确认、样机实测和耐久试验分别记载；“文件可打开”“无干涉”“性能满足”“与实物核对一致”各有相应证据范围。
- 从零设计且尚无样机时，可报告已完成的设计、制造装配审查与计算检查，以及待采购、试制和实测项目；不得虚称已与实物核对或已完成使用性能验证。

## 可复用完整流程提示词

> 使用 $fusion-production-modeling，从方案设计开始完成面向实际制造、装配和使用的机械产品设计。先整理用途、空间、载荷、运动、环境、寿命、操作维护及成本等适用要求，为关键指标建立依据和验收方法，区分确认事实、计算、拟定与待验证数据。建立简洁可行的基础方案；涉及申请专利时提前查新，说明实际不足、区别结构与配合、作用机理、效果及代价，执行删除/合并/常规替换检验，不为形成区别而增加无实际收益的结构。按需要完成关键计算，以结果确定采购配置、传动、截面和尺寸，再确定基准、总体布局和接口。逐件落实真实工艺、定位紧固、密封、装拆、倒角圆角及连续管线，区分自由态、安装态和工作态，分别管理成品尺寸与制造余量/补偿。按阶段自检并主动整改，核对公差极限、全行程、工具空间及本案工况。交付可编辑原生总装、STEP、同版BOM、必要制造图及验证记录，重开和重新导入复验并清理隐私。已有实物先测绘及确认型号；试制后对照测量、装配和运行结果查明差异，修订关联文件并复核。未进行的检查及实测试验保留待验证状态，结论对应实际证据。

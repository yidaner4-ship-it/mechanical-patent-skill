# 现实零件与圆滑管线

## 先确定参照，再建常见件

目标是使常见件在真实使用场景中看起来合理，且规格、加工和安装相互一致。局部改模先核对当前件的零件族与接口，替换外形后联查配对件及操作空间。

- 优先采用所选厂家的官方CAD和尺寸图；按标准重建时核实标准版本、系列和实际规格。官方产品照片可核外形和细节，不能从透视照片臆定精密接口尺寸。CAD、尺寸图与照片冲突时追查版本及型号，记录采用依据。
- 参考落实到BOM：零件编号、制造商、类别/系列、具体型号及选配项或拟定规格、来源链接/图号与CAD版本及来源日期、关键尺寸、简化范围和确认状态。同型重复件复用定义；不同系列或配置的特征不能随意拼接。关键采购接口必要时由供方图纸或实件复核，选型变更后联查支架、孔位、连接及操作维护空间。
- 标明“采购件/按供方图重建”“按标准重建”“工程拟定自制件”或“待选型包络件”。无供方图时可作合理工程设计，明确自制路线或待选型状态，不宣称与某型号完全相同。包络件只支持已经核实的空间判断；承担本轮操作、安装、密封或真实外观表达的部位继续细化。
- 看外形与查接口分别进行。圆盘和圆柱可以作为建模起始特征，成品应有该类现实件可识别的结构和合理比例。无需复制与任务无关的商标、装饰或不可见内部构造；保留影响制造、安装、操作、运动、密封及外观判断的细节。

## 按所选零件族核对

以下项目按实际类型选用，不把示例特征强加给不适用的零件。

| 常见件 | 成品应能核对的特征 |
| --- | --- |
| 手轮、旋转把手 | 与所选类型一致的轮缘截面、轮毂及辐条或实心腹板、握持轮廓、轴孔/键/方孔、锁紧及轴向保持；旋转小握柄核对销轴和止退，折叠型核对铰接与锁位。检查手位、回转包络及传矩路径 |
| 杠杆、阀门手柄、旋钮 | 实际杆形或冲压折弯轮廓、握套/防滑形态、根部连接、止挡/分度及锁定机构；长度、厚度、偏置和转动方向与受力及空间一致 |
| 法兰、卡箍及密封接口 | 先分清平焊/带颈/对焊等法兰族或卫生卡箍接头等接口族；核通径与实际内径、外径、厚度、孔数孔圈、孔径、颈部/焊端、密封面/槽及垫片、配对件与真实紧固件。不同体系及系列不能只因外形相近而混配 |
| 管接头、阀体、压盖 | 真实对边和扳手位、台阶、螺母/卡套或卡箍边界、插入/螺纹有效长度、肩部与密封结构、接口方向；薄型、卡套、快插、螺纹等系列按其实际构造表达 |
| 螺钉、螺母、支脚、支架及机电件 | 所选规格的头型/驱动口、承压面和垫圈、有效长度、孔距、轮廓与尺度；外壳凸台、安装脚、端口及出线与所选件一致。加工倒角、圆角及表面处理影响的配合一并核对 |

## 倒角、圆角与过渡做成实体

逐件检查可触边、握持边、板管端口、孔槽入口、装配导入、台肩根部、切削内角和成形折弯。按工艺、材料、壁厚及所选实物确定尺寸，实际建入模型；只写“去毛刺”或靠显示平滑不能替代本轮应表达的几何。

同型件采用一致且合理的边缘处理，避免将所有边一律施加同一数值。密封棱边、定位肩、刀口、焊接坡口或标准接口须保留的特征按功能和依据处理。完成后重查最小壁厚、接触面、孔口有效长度、工具可达和相邻件干涉。极微小且不影响本轮判断的倒钝可作明确工艺标注，说明几何简化范围。

## 管路与线束连续过渡

- 确认采用弯制整管、标准弯头加直管、软管还是线束；按实际制造和连接方式拆件。中心线在应连续的位置相切，扫掠截面及壁厚沿真实路径连续；直段与圆弧间不留折点、尖角、错台或间隙。
- 弯曲半径据外径、材料、壁厚、工艺或所选弯头/软管规定确定，并核相邻弯之间的夹持直段、两端插入直段及安装方向。没有依据时记录拟定条件，不用统一任意圆弧替代选型。
- 变径采用适合工艺的锥形或曲面过渡，接头接口维持所选件的真实肩部与密封面。结构本来有台阶、T形支路或接头分界时保留，圆滑要求不应抹掉真实功能边界。
- 管路检查内外轮廓、实际连通、接头配对及拆装；线束/软管检查最小弯曲半径、端口出线方向、线夹/护圈、应力释放和随动余量，复核全行程。连续曲面显示只是线索，仍要测切向、剖面与真实实体。

## 成品验收

在最终保存并重开的模型中，逐件或按同型件定义加实例清点完成下列核查；高风险或改动处给局部视图/剖面和尺寸证据。

1. 参考图/CAD与成品按可比方向并排对照，检查轮廓、比例、特征位置和所选规格。外形合理与接口一致均需通过。
2. 在实体中量关键接口尺寸，检查配对件、定位保持、工具及手位、运动和拆装。截图相似不能代替尺寸及装配验证。
3. 查看该件应有的倒角、圆角和过渡，登记保留功能边或几何简化的位置与依据；检查处理后的壁厚和配合。
4. 对管线测连续段相切性及最小弯曲半径，查内腔连通、壁厚、端部插入和实际接头。再查总装的干涉、间隙及相关工况。
5. 记录通过、整改后复核、工程拟定或待选型及其影响。未完成的常见件占位或参考缺口写到实际版本的待确认项，完成度与证据一致。

## 可复用建模提示词

从方案设计起步、方案优化或还原实物时，使用[完整流程提示词](design-development.md#可复用完整流程提示词)。已确认方案的逐件建模可使用以下提示词，并沿用已有设计依据：

> 使用 $fusion-production-modeling，依据已确认方案、关键计算与实际工况建立或优化机械总装。先按制造与采购边界拆件，为常见件确定真实制造商、型号配置及可追溯图纸/CAD；同时核对外形比例和功能接口，细化操作件、法兰、接头、紧固件及真实保持结构。逐件把适用的倒角、圆角、工艺与装配导入做入实体；管路和线束采用有依据的弯曲半径及圆滑连续过渡，保留真实接头边界。无资料的细节作可逆工程拟定并标明来源状态；关键待选型接口保持待确认，选定后替换复核。用最终成品检查现实零件相似度、制造装配、公差净空、运动及本案工况；交付可编辑原生模型、STEP、同版BOM、必要制造图和核查记录。需与已有实物或试制样机核对时，按同版本测量、试装和运行记录处理差异，结论限于实际证据。

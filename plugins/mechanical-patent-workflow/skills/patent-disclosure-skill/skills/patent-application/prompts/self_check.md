# 申请文件 · 自检

内部执行，不写入说明书或权要。

- [ ] 已分开核定专利类型与保护对象、材料来源、程序阶段及有效底稿；可内部整理的资料未重复索要，缺口已按实际影响分诊。改稿另存新目录
- [ ] 已有实际从属树；机械独权完成试删／替代复核，从权按后备构造及真实依附关系组织，不强套算法层级
- [ ] 已按[共同细则](../references/claim-scope-and-names.md)独立复读独权的总体构思与逐限定取舍，未以支持、检索区别、标号或字数代替上位/简洁/抽象验收；正式名称全稿统一，未用括号保留另一个特征名，主方案、摘要和结尾同步
- [ ] 机械权项及说明书的新特征先说明有据的所属、所在或组成和连接关系，再展开细节及作用；逐处回到首次引入句和实际引用链核查，未用标记表、平行从权或名称次数替代，独权仍保持必要核心层次
- [ ] 实用新型说明书的“实用新型内容”章节只用正式名称、不带部件附图标记；按实际章节检查无裸号或括号号残留，名称检查仍执行，图号及技术数值保留，其他栏目按各自规则核号
- [ ] 机械产品附图来自核验后的CAD／可信结构图，未重画成算法图或无依据改变几何；方法／软件逻辑图按相应分支处理
- [ ] 软件框图和方法流程图的专用格式仅用于相应对象；机械部件与子特征保留核定标号及引线
- [ ] `audit_claims.py` 无 ERROR；第二条系统/装置独权不应再报 `NO_REFERENCE`；`SAID_ANTECEDENT` 警告已处理或已记问题清单
- [ ] 部件／子特征登记、逐段图文覆盖和逐根引线已实际核读；纸面样式、图号和版式按机械权威参考核对
- [ ] `check_support.py` 无 ERROR；已写内部 `对照表.md`
- [ ] 摘要≤300字、无宣传语；机械摘要图体现核心构造，方法／软件按实际主方案选图
- [ ] 机械背景从有据的使用场景与结构不便起笔，文献按需核引，不强行点名；无检索列表、URL或检索腔
- [ ] 交底 `formula_plan.yaml` 若存在：说明书符号+式面+数值例与计划同义，权要只有文字关系
- [ ] 点名图已判别入文或拒绝；未扫工程素材
- [ ] 所需实际Word与图页已生成并渲染；失败的文件／图页登记未完成范围，未以列清单替代完成
- [ ] **行内公式分隔符**：`emit_application_docx.py` 若打印 **`DOCX: ok=0 reason=latex_delim`**（stderr 另有 **`LATEX_DELIM: hits=`** 与 `LATEX_DELIM_FILE:`），说明该文件把行内公式写成了普通括号（如 `(M_{\mathrm{total}})`）。**该文件 Word 未写出**。须改成 `\(…\)` 后重跑脚本，不得交付坏公式 Word；确无法改则记问题清单
- [ ] 交底里的多行对照/参数表已作为说明书「表N」保留，未收成段落
- [ ] **外观**：已按 `design_view_cnipa.md` 核查；原样复制入文图，未跑 `compose_application_figure.py`、未改原图像素；已选定全线稿或全实拍；不合格（落面、省略用语、混交、投影、图幅/DPI）只写入问题清单，未默补假面
- [ ] 问题清单已写（含对照/权要/附图机器结果，外观含 4.2 核查）；同一条交付回复末块为 **`## 交付后请确认`** 且已给出清单路径并摘要条目；未宣称通过附图审查

# 申请文件 · 总则

## 机械结构案的适用口径

机械结构类发明和实用新型先读[申晟撰写风格](../../../../mechanical-patent-drawings/references/shensheng-drafting-style.md)。下文“发明系统/模块不写件号”“主流程图作摘要图”等约定仅适用于对应的方法、软件或算法系统；机械产品按部件名称、件号、连接与配合撰写，摘要图选能体现核心构造的已有图。背景从有证据的使用场景与相关结构起笔，按需要引用具体文献，不为套模板强行点名或编造对比文件。检索证据仍按原流程留在内部底稿。

## 定位

已有交底包时，写出权利要求书、说明书、说明书摘要、说明书附图。交底提供技术方案事实；说明书按申请书式撰写。Word 可再转 PDF。

主交付：权利要求书、说明书、说明书摘要、说明书附图（含从本案适合视图选择的摘要附图）。  
旁路：`问题清单.md`。不要把问题写进正式三件或附图。交付回复末块须为 **`## 交付后请确认`**（见 `issues.md`）。

不做：请求书、费减、序列表、发明人签章、XML/CPCNS 客户端包、TIFF、海外申请。  
正文生成不自行给出未经检索的新颖性、创造性结论，也不承诺授权。机械申请定稿由[指定检索入口](../../../../mechanical-patent-drawings/references/patentability-review.md)实际检索并评价，独立质检复用对应版本证据。首次成稿、改稿均回[共用收尾](../../../../mechanical-patent-drawings/references/drafting-and-review.md#共用收尾)。

## 输入

使用同案核定材料，已有文件不要求用户重复制作：

- 交底书（时间戳 `.md`，有则兼用 `.docx`）
- 机械产品（发明或实用新型）：交底、结构及子特征台账、图页计划、可信结构线稿；已有Word／模型可内部整理为工具输入
- 方法／软件系统：交底正文及确有依据的流程／框图
- 外观：`appearance_schema` + `figure_plan` + 入文实拍/线稿

缺材料先核已给文件及可内部整理内容，继续完成有依据部分；关键事实缺失不编造。可选写法记录清单，确定错误整改；按共用收尾区分阶段成果和正式定稿，不能把缺图、缺前置等仅记清单视为已完成。

## 主文件纪律

- 正文用申请书式，不要写「草稿」「须人改」「待确认」、质量分、仓库脚注、检索说明、来源 URL
- 背景消化已核现有技术；机械案从真实场景和结构不便起笔，按需要引用具体文献，不强行点名。方法／软件案引用最近对比时优先写透，必要时再补其他做法。具体见 `specification_builder.md`。
- 发明内容为问题、独立方案、按从属树展开的必要从属要点、有益效果
- 发明方法：独权、附图、实施例统一用「步骤一、步骤二…」；流程图框内写步骤正文，**不**拉引出线，**不**另标 201、202、S1
- 发明系统/模块独立权项只写模块名称，**不**写（10）（20）；系统框图框内写名称，**不**标件号、**不**拉引出线
- 机械产品结构图用本案部件及子特征标号和引线；申请附图须核验同源几何、黑白和实际图面，不能直接使用未经处理的彩色截图
- 外观视图按 `design_view_cnipa.md` 核查，并跑本包 `check_design_views.py`；原样引用交底入文图，不升格、不改像素；漏视/虚线/新事项写入 `视图检查清单.md`，摘要进问题清单
- 公式、符号、交底已有的多行对照/参数表默认写在说明书具体实施方式；表题「表1」起编号，不进权要、不当附图。交底已有表不得改成一段叙述；交底没有的表不要编。权要只保留审查必须卡住的计算关系，整式不要塞进权要。交底有 `formula_plan.yaml` 则说明书与权要文字关系与之同义
- 摘要不超过300字、无宣传语；机械案选核心构造图，方法案选能说明主方案的流程图，软件系统案按核心方案选框图或流程图
- 附图黑白线框；图号写在说明书正文，不要画进图里；PNG 按内容包围盒截取。用户点名或交底已入文的场景图可作 `source_image`，不扫工程素材、不承诺重画
- 交底 mermaid 彩色 PNG 只当结构来源，不得当作说明书附图
- 已有申请产出上改稿：新时间戳目录，不覆盖旧目录

## 禁止

- 无本案材料或关键事实依据仍编造完整申请；仅凭未经核定的聊天推测填补技术事实
- 宣称已通过国知局附图审查或电子申请格式校验
- 外观案套用发明权要
- 外观案用 `compose_application_figure.py` 改交底原图，或为省略面默补假面
- 自动堆装置 / 介质 / 系统权要（交底第五章没有对应对象就不写）
- 扫描前端或工程素材目录当附图
- 覆盖上一版申请产出目录（用户明确要求覆盖除外）

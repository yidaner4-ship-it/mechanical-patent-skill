# 申请文件 · 迭代上下文

已有申请四件套上继续改时，先读本文，再读 `iteration.md`。不要回到交底挖点，也不要未落盘新目录就空改旧稿。

## 输入

- 对话中的修改说明；用户 **@** 的上一版产出目录或其中文件。
- 交底目录：沿用上一版计划或同案核定材料；当前Word、模型及原图已有充分依据时可内部整理，不要求用户为缺 `case_dir` 重做资料。
- 点名补图：只处理用户指定的路径，见 `figures.md`「点名图」。
- 机械案按[接入与定稿收尾](../../../../mechanical-patent-drawings/references/drafting-and-review.md#接入与定稿收尾)先确认程序阶段、工作底稿、适用原始申请基线及补充来源，再作实质调整；不能只用当前稿自证申请后修改依据。
- 分开记录专利类型与保护对象；核对本轮是文字／版式修改，还是权项特征、组合或技术效果改变，以确定补检和复核范围。

## 输出

新时间戳目录 + 该目录内四件套 Word + `问题清单.md` + 本目录 `申请文件修订对话记录.md`。旧目录保留。

用户明确要求覆盖某路径时从其意。

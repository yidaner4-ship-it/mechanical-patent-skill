# 专利文稿与真实修订

## 接入与定稿收尾

机械结构类交底、申请稿及改稿共用本节；局部任务只执行相关部分，不扩写用户未要求的内容。现有风格原文与已认可附图样例继续适用。

### 规则归属与接入

| 内容 | 唯一细则来源 |
| --- | --- |
| 权1取舍、术语及结构叙述 | [申晟机械撰写风格](shensheng-drafting-style.md) |
| 本案接入、模板、范围调整与真实修订 | 本参考 |
| 取图、标引、纸面样式、图号及图页验收 | [CAD取图与附图验收](cad-figures.md) |
| 定稿检索与新颖性、创造性评价 | [定稿前检索与两性评价](patentability-review.md) |
| 独立审阅、整改、复用与交付清理 | [申晟独立质检](../../shensheng-patent-qa/SKILL.md) |

各入口保留必读链接与执行提醒，条件、参数与例外在上表对应来源维护。旧通用模板或脚本结果与机械规则不一致时，修正相应分支或记录工具未覆盖项，不以错误输出替代核验。本案最新指令、认可底稿和本轮范围优先；不改变已确认的技术事实和必要保护关系。

开始时在现有技术底稿或计划中记录：

- 专利类型与保护对象分别确认；发明可保护机械产品，不能用结构schema、名称中的“装置”“模块”反推专利类型或图型。混合案件按实际产品、方法分别规划。
- 确认申请前、审查中、授权后或阶段未确认；确定工作底稿及适用的原始申请基线。申请后新增、概括或改变组合时回查原始提交材料，不能以最新工作稿代替原始修改依据。阶段或基线缺失时，先做有依据的文字与形式工作，实质修改保留待核。
- 核定材料包括有效交底、可核对的模型及原图、用户确认并留存的补充。申请前补充技术事实先更新技术底稿并记录来源；事实、工程推断、设计建议和待验证效果分别标明。边界假设不能自动转为申请正文中的技术事实。不要求用户另造目录或重复提供已有材料。

### 共用收尾

首次成稿与每次改稿均回到本节。交底执行适用的自检与独立质检；申请稿及权项实质变更还执行定稿检索或补检。

1. 按当前对象检查必要特征、真实引用链、说明书支持及逐段图文覆盖；脚本意见先核实，确定错误直接修复，误报写明依据，不能为消除机检误报改坏正确技术文字。
2. 按[定稿检索与两性评价](patentability-review.md)确认报告对应当前权项。已核证据可复用，新增或改变的特征及组合补检；仅排版等不影响方案的改动不重复检索。失败来源、日期待核和覆盖范围如实记录，不以生成正文代替检索完成。
3. 按[独立质检](../../shensheng-patent-qa/SKILL.md)审阅实际文件、整改和复核；复用既有记录须满足其版本、依据及范围条件。权项实质整改后返回第2步处理受影响范围。
4. 在问题清单或审核记录中区分下列状态，不新增仅为记状态的重复文件：

| 情况 | 处理与交付状态 |
| --- | --- |
| 已确定且有依据可修的错引、错号、缺前置、格式或生成错误 | 交付前整改并复核；工具误报核实驳回 |
| 著录信息未填、不影响所选技术方案的备选等 | 可非阻塞保留，说明待确认项 |
| 关键构造/修改依据缺失、必要图页未生成或未核、独立质检/检索未完成 | 完成其余有依据部分并交付阶段成果，明确未完成范围及影响；不能宣称正式定稿或已完成相关验收 |

5. 从同一确认稿同步合册、分册Word和独立PDF，渲染核对。按用户AGENTS清理全部实际交付副本的隐藏身份、时间、工具与内部路径；保留用户要求的真实修订功能并匿名化。清理后复核可打开、内容、图页和版式，记录最终摘要值。正式交付包不含内部日志、审核源数据或备份。

## 交底与申请稿

- 先确定是交底还是申请文件。交底可写现有技术、要解决的技术问题、结构与工作过程、技术效果、实施变型、附图说明和待确认事实。用户只要交底时可把文字交底和图PDF分开交付。要求嵌图时把实际图片写入 Word 文件并逐页查图。
- 五书包括说明书摘要、摘要附图、权利要求书、说明书和说明书附图。有用户指定或已确认的模板时按[用户模板套版](#用户模板套版)制作。
- 申晟实用新型沿用本次确认的模板字体时，正文、权项编号和图号用小四宋体，案名和说明书正式栏目标题用小四宋体加粗，五书页眉用四号宋体，页码数字用 9 磅 Times New Roman。用户当次提供不同模板时，按当次模板的有效文字格式设置。
- 栏目名称按申请类型分别采用“发明内容”或“实用新型内容”。复杂机械案按结构树组织具体实施方式，申晟申请稿的“发明内容或实用新型内容”“具体实施方式”保留正式栏目标题，栏目内部全部用正文段落。具体实施方式首段在结合附图的引入语后，简要说明主体设备、主要装配关系以及各一级模块的划分。后续用自然过渡逐模块展开，写清子部件组成、位置、连接或装配、运动或流路和作用。末尾结合工作过程串起各模块的配合。模块名称取自本案实际构造。
- 在介绍某个结构、配合或动作的段落中首次引用能够直接展示该内容的附图。整机段引用总览图，后续随各模块介绍相应图，局部图和剖视图在相应母图之后引入。范围引用仅用于其中各幅图都服务于当前叙述的情况。最终以具体实施方式首次实质引用的次序确定图号，其他栏目不参与排序，用户锁定图号时记录例外；按 [CAD取图与附图验收](cad-figures.md#附图编号与正文引用) 同步文档。
- 逐段搭配图和文。正文段落引用一幅图时，该段的所有附图标号均在这幅图出现。引用多幅图时，这些标号由所引各图共同覆盖。先在现有适合的视图补齐可辨认的标引，其次调整贴合本段内容的图号，或按结构和配合关系拆成连续的自然段。配合、方向、开合或装配状态分别引用能说明它们的视图。按[逐段图文覆盖](cad-figures.md#逐段图文覆盖)复核，保持段落自然和引图集中。
- 同一套模块名称用于权利要求组织、发明内容或实用新型内容、具体实施方式和附图台账。发明内容或实用新型内容先说明技术问题，再依权项顺序写技术方案，包括独立方案和逐项进一步方案。每项方案后紧接独立的效果段，可按模板以“通过采用上述技术方案”衔接，具体说明该项结构如何产生该项效果。必要时可依模板增写整体有益效果。正文的一体、分体和有线、无线等可选方式分别交代适用条件和必要部件。只将材料可辨认或用户已确认的结构写为事实。示意图应指回对应的实施方式。
- 以资料或用户确认的产品构型起笔，分清原有状态、改进动机和引入新构型后要处理的问题。例如，已确认原设备两个部件固定连接且不可拆卸时，先说明搬运、收纳或维修整件的不便，再说明采用可拆卸构型后需要处理的重复装配对位及连接问题。保持背景事实的范围，避免从本案的附图倒推原有产品的结构，或把本案接头构造写成已知结构。
- 具体实施方式开头和末尾按模板与案情调整常用语。开头交代结合附图阐述技术手段、结构特点和实际作用，再落到本案整机。末尾在介绍完整工作过程后补写实施例与保护范围的表述，保护范围以所附权利要求及其等同范围为准。模板中的产品名、图号、法律口径对应到本案，保持技术披露与权项支持一致。
- 多案共用说明书框架时，按用户同意的分组共用技术披露。每案仍按本案保护对象组织背景、技术问题、权项及摘要，核对技术问题、技术手段和技术效果一致。摘要写明技术领域。
- 写流路、装配或检测时，按材料逐段核实入口、转接、分隔、出口或排液，区分相邻独立通道。传感器交代有据可查的安装端、检测对象及两者配合。已有结构靠操作实现对位或保持时，按已证实的装配关系与动作描述。额定值、导入倒角、自动锁止等缺少依据时列为待核。有实体证据但视图受遮挡的部位按图文覆盖规则处理。
## 用户模板套版

1. 起草或改稿前定位本案指定模板。续改时沿用本案用户已确认的母版。用户说“以前的模板”时，先查本案历史交付与工作区，申晟实用新型可核对桌面的 `实用新型模板.doc` 是否为所指版本。无法定位时先完成有依据的正文，说明成品尚未套用指定模板。没有指定或已确认母版时采用现有默认书式。
2. 以实际母版的独立副本填充，旧格式可在副本上转换后使用。通用 Markdown 转 Word 的输出可供提取已校对的正文和公式，正式 Word 从母版制成。文字部分沿用母版的五书顺序、页边距、段落样式、行距、标题、自动编号、页眉页脚及页码。附图页落实当前用户默认的一图一页、顺序编号、图体水平及垂直居中、页脚图号和局部断裂线。母版与此默认不同时，调整附图分节及页脚并记录版式变更。用户当次明确指定其他版式时按当次要求执行。
3. 在清理后的拟交付 Word 与 PDF 中复核分页、实际生效的中西文字体及字号、页眉页脚、图号及页码的位置，并对比母版。合订与分册采用同一母版对应部分。独立附图 PDF 从同一确认图稿派生，检查图面、图号及页序与 Word 对应。

## 独立质检与整改

成稿和实质改稿默认按[申晟专利独立质检](../../shensheng-patent-qa/SKILL.md)执行，使用 `patent-draft-review` 与本技能逐图逐根标准。该独立入口取代原来默认强制 Work Buddy／DeepSeek 的送审步骤；用户当次指定平台时再追加，其他检索及成品复核要求不变。

1. **冻结实际文件独立审阅。** 用本轮拟交付正文、Word、独立图 PDF 和必要原始依据交给未参与起草的审阅者；记录版本。分别核对技术逻辑、公开充分性风险、形式支持、每次标记落点及引线图面。附图必须实际查看，未核项目写明原因。
2. **报告定位到原件。** 每条意见包含编号、严重程度、文件及页／项／段／图号和标号、原文或可见部位、依据及建议。图面按同一标号的每次出现核查，不能以文字抽取或几何接近代替正确归属。
3. **逐条核实整改。** 对照案卷及 CAD 依据，采纳成立意见，驳回误报并写理由；缺技术事实的列待确认，不编造。用户提供的其他质检报告也先核版本再按同法处理。
4. **复核最终版本。** 用整改后的实际文件重新核对原意见、关联正文、同号图及相邻引线；记录已关项和遗留项。同步实际交付各副本，完成渲染和隐私清理后再交付；报告不能把生成成功写成技术审查通过。

## 权项与范围

1. 先确定各独权的保护对象、要解决的具体技术问题和体现构思的结构配合。逐项试删部件和限定，并以可预见的替代设计检验安装侧、传动形式、形状与尺寸等限定是否确有必要。逐次核对剩余组合能否维持该配合并获得材料支持。把维持核心配合所必需的结构、连接、相对位置或运动关系写入独权，将有后备保护价值的实施细节放到从权。同案有组件和整机独权时分别检查。
2. 概括时从交底、说明书和附图提取可推广的共同结构及其关系。可对零件形式、外形或安装位置作概括，保留使作用成立且能识别的连接、配合或约束。描述功能时，同时写清承担功能的结构及其必要关系。用闭合、分离、接合等状态表达配合时，先交代部件的安装位置和可动关系，再交代各状态下的接合、分离或限位关系。用具体运动方向限定独权前，先核实该方向是否为核心配合所必需，若仅是可选实现且有支持，可在从权限定。将每处概括回映到可实施的结构、对应图页和文字披露。以假设的替代设计检验范围，以原材料和允许使用的补充披露支持写入申请稿的特征。原材料仅支持特定方案时保留构成该方案的必要限定。
3. 从权以一个有独立后备价值的构造或一个需要共同限定的配合为中心，直接写出新增的结构及必要关系。已经由引用项继承的结构和关系只在引出新增限定时回指。能够直接并入独权的后备方案可直接引用独权。利用上项新引入部件的方案引用建立该部件的相应权项。并列变型分别有引用基础。删去重复效果、同义复述和没有独立后备价值的层级。保护范围因精简发生变化时，复核必要的配合构件是否写齐。
4. 上位、下沉、合并或删除后，逐项复核保护对象、先行基础、引用链、新增限定和可实施性。将权项旧新结构对应在工作底稿中，回查说明书和附图支持。按新权项顺序更新发明内容或实用新型内容，逐项写出相应技术效果，同步核对摘要、实施方式、标号表和附图。具体实施方式继续披露支撑各层权项的具体构造。
5. 以标记台账逐项查独权和从权。所有能定位到附图的部件、孔、槽、配合面及功能区均应有对应标号，尤其是容易遗漏的上位结构名称。概括名称与实施例名称指向同一实体时，沿用可对应的附图标号。上下位结构确有不同指认对象时，在说明书写清实现关系，并通过可核对的视图给两者锚点。文字披露而未在图中呈现的部件记录在台账，保留用户指定的权项标号省略项。改动后核对摘要、发明内容或实用新型内容、实施方式、附图说明、标号表与权项术语，逐条检查先行基础、引用层级和结构支持。正文使用标号时同时核对标记实际落点与文字描述的所属部件、几何部位、方向和装配关系。逐个查同号在各图中的对应部位。将上位称谓在从权首次具体化时先写明对应关系，同一实体沿用同号。核对局部特征的母件及先行基础，例如明确外缘属于哪个容器、面盖属于哪个组件，名称对应实际接触边。沿用本案既有编号体系，标记表按部件族分组，同组通常按数值升序，写清复合子号的归属。复核方法和核查表见 [逐个核查附图标记与说明书](cad-figures.md#逐个核查附图标记与说明书)。
6. 每件中国发明或实用新型完成申请稿后，按[定稿前专利检索与两性评价](patentability-review.md)以本版权项实际检索、判断两性。检索后或质检后实质调整权项的，对变化的特征和组合补检并更新报告，再核对说明书与附图。

## 权项用词与方向关系

- 用户要求尽量完整标号时，从每项权利要求逐句提取部件、上位总成、孔槽、开口、台阶、接触边、间隙和流道等可定位特征。逐处补已有编号，连同同一权项中的回指和继承特征一起检查。所指是同一实体时复用原号。确有可单独定位的子特征而无编号时，在能辨认该特征的已有视图、剖视或局部图上补标，并同步实施方式和附图标记表。流道和间隙的引线落在能辨认的真实通路界限或空间。相对方向、动作、位置关系和缺少明确定位依据的特征用准确文字表达，并在核对表记录保留理由。补标前后逐项比较技术文字和引用关系，确保编号对应原来所指。

- 每项权利要求直接写出动作、位置或配合关系涉及的部件名称。回指已出现的技术特征时用“所述＋特征名称”。有多个部件、端部或相对面时，分别点明归属及配合对象。例如将“沿其长度方向”写为“沿所述插拔底座的长度方向”，将“设于各自的定位部”展开为各侧电连接部与同侧定位部的对应关系。“其特征在于”按权利要求固定句式使用。
- 选用能准确识别结构的简短名称。名称可以保留区分侧别、层级或对象所需的限定词。例如“垫体侧排母连接件”可用“垫体侧排母”。定名后在权项、摘要、说明书和附图标记表中统一使用。缩名称时核对技术含义和保护层级。
- 区分指向对象与方向一致。“插接端朝向主机侧插接部”交代插接端面向的对象。“垫体侧插接端的朝向与配合侧的朝向相同”比较两处结构的方向。凸部和开口分别比较“凸出方向”和“开口朝向”。以相应装配状态下的模型、附图或经确认的装配关系核对，位置、起始面和接触关系有依据时再单独表达。

## 从已定稿接受态开始修订

1. 冻结用户指定的定稿，另取工作副本。若底稿仍有历史修订，先在副本物化历史修订的接受态并检查与用户认可的正文一致，再开始本轮。保留源文件可供回溯。已经存在的图片、表格、批注、分节和附件关系按任务范围处理。
2. “基于已定稿”用于确定底稿，是否跟踪修订依据用户要求或同轮上下文。用户要求修订模式时，使用 Word 原生的修订功能，或采用 OOXML 原生修订元素。删文和新增用独立的跟踪对象，控制改变范围。仅把本轮实际增删作为修订。只给字体着色或描线无法保留接受/拒绝功能。用户指定默认显示方式时按其选择，未指定时通常展示当前修订便于审阅。
3. 使用 OOXML 时，`word/settings.xml` 启用 `w:trackRevisions`，文本插入用 `w:ins`，删除用 `w:del` 和 `w:delText`。为本轮分配唯一 ID 和审阅者。新增或删除整个段落时检查段落标记修订，使接受和拒绝均恢复预期正文和段落边界。图片和页眉变更涉及分节或图片资源时同时核对 ZIP 关系与原有文字修订。直接改图片资源或设置时，应单独验证其可否通过 Word 的修订接受或拒绝还原。
4. 建立当前修订的接受态和拒绝态进行对照。接受态与拟稿相同，拒绝态与指定定稿相同。分别核对权项、页眉页脚、标号字典和附图；渲染查看修订界面与接受后的最终版式。图稿只改了局部时，可对原图和正文资源做哈希或像素比对。

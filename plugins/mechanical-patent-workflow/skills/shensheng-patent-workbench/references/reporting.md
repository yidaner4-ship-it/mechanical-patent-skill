# 申晟品牌交付

## 共用原则

- Excel、Word、PDF 必须来自同一 `evidence.json`，不得分别手填出互相矛盾的结论。
- 使用 `assets/shensheng-logo.png`，保持比例与完整字样；机构法定全称、地址、电话、承办人、复核人和签章均保留占位，不臆造。
- Word/PDF 默认 A4 纵向；超宽矩阵使用独立 A4 横向节。品牌色取主蓝 `#174D92`、深蓝 `#0F3E78`、浅蓝 `#EAF1F8`、正文 `#1F2937`。
- 报告名称使用“专利检索与分析报告”或任务专名，不在缺乏授权时称“法律意见书”。

## Excel

只读源模板：`assets/templates/申晟知产_专利检索候选表模板.xlsx`。`init-case` 会把它复制到案件 `working/templates/`；只填写案件副本，不得回写 Skill。

核心表：案件概览、候选文献、技术特征、特征证据、检索日志、官方核验、字典与说明。模板已内置 `OA映射`、`FTO权项映射`、`无效证据链`、`竞品路线` 四张任务专表；案件副本只填写适用表，未使用的任务表保持空白或在成品中隐藏。

FTO 的 `官方核验` 与 `FTO权项映射` 必须共同填写 `权利实例ID`；前者记录目标国权利标识和全部当前有效权项，后者逐条填写本映射所依据的具体有效权项，确保国家、权利实例、权项和产品特征可追溯。

所有汇总使用公式；日期用 `yyyy-mm-dd`；状态和枚举使用数据验证；来源 URL 独立成列；冻结表头及关键列。空白与 0 不混用。交付前检查关键范围、公式错误并渲染每张表。

## Word 与 PDF

只读源模板：`assets/templates/申晟知产_专利检索分析报告模板.docx`。`assets/templates/申晟知产_专利检索分析报告模板.pdf` 只是该空白 DOCX 的版式预览，不是第二内容源，也不能直接作为案件成品。

封面：完整 Logo、报告类型、项目/案件名、客户、任务、法域、关键日、数据截止日、报告编号、版本、日期、保密级别。

正文最小章节：任务与边界、执行摘要、目标方案和机械特征、检索策略与日志、候选筛选、逐文献特征对照、任务专章、官方核验、结论与建议、局限和附录。

每篇重点文献优先采用四列纵向表：特征 ID、目标特征、证据定位/短摘录、判断与任务作用，避免把长段文字塞进超宽矩阵。证据定位精确到权项、段落或附图，并标明明确、推断或缺失。

案件 DOCX 每次实质修改后渲染为逐页 PNG 检查。正式 PDF 只从通过检查的案件最终 DOCX 转换，再用 Poppler 渲染全页复核；`deliverables/` 只放完成终验的成果。

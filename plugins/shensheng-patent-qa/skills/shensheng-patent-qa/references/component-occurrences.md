# 部件名称与标号逐处核对

本项检查适用于机械文稿中已确立的名称和标号。按用户指定的标号习惯检查每一次出现，记录具体位置。同一句前面或其他段落已经有标号，均不能代替当前这一次的检查。

## 文稿核查

1. 从实际标记表、权项和已核图中建立本案名称—标号对照，登记上位名称、具体名称和确实指同一对象的简称。例如「安装座」「环形安装座」可指同一部件，但不同零件上的「安装孔」可能各指不同对象，须沿归属判断。
2. 显式登记各段落的标号格式。具体实施方式按核定习惯逐次紧跟标号；权项沿用指定括号格式。摘要、技术领域、实用新型内容、图名或标记表本来省号、前置编号时，分别登记该段的格式依据。不能把整篇同一个词统一设为豁免。
3. 对每处名称分别判定有号且一致、漏号、错号、同物异名、同名异物或经核定例外。名称嵌套按最长完整名称识别，例如「插拔上盖」中的「上盖」只记一次。「分隔壁段」中的「隔壁」不直接视为相邻通道的隔壁；「第一组出光通道」不自动当作单个通道。遇这种词面重叠须回查原句、母件和附图。
4. 对字典未覆盖的简称、合称、代词、并列省略和新引入部件进行人工通读，补充实际名称或逐处判定。例如「主机侧电连接件」内的「主机」与独立回指主机的用法不同。「安装孔」「开孔」应沿所属零件判定。自动匹配结果只是候选清单，不能据此直接批量补号。
5. 图面另按每图每次标号逐根核落点。对正文每处标号展开本段引图，确认所引图合计覆盖该标号及配合关系。纯名称或编号集合、图片资源哈希一致均不能代替逐处核查。

## 辅助脚本

`python scripts/audit_component_occurrences.py 五书.docx --config 本案名称标号.json --output 名称标号逐处表 --view accepted --fail-on-issues`

脚本仅用 Python 标准库。JSON 配置使用下列字段，段落序号从 1 开始，按所选接受态或拒绝态计算，含空段。每个段落必须归属一个明确的段落规则。先不加 `--fail-on-issues` 查看候选，逐处审定后再用于验收。

```json
{
  "components": [
    {"number": "223", "name": "安装座", "aliases": ["环形安装座"]},
    {"number": "22", "name": "上盖", "aliases": []},
    {"number": "342", "name": "插拔上盖", "aliases": []}
  ],
  "regions": [
    {"name": "摘要", "start_paragraph": 1, "end_paragraph": 4, "mode": "exempt", "style": "either"},
    {"name": "权利要求", "start_paragraph": 5, "end_paragraph": 22, "mode": "required", "style": "parenthesized"},
    {"name": "说明书前部", "start_paragraph": 23, "end_paragraph": 79, "mode": "exempt", "style": "either"},
    {"name": "具体实施方式", "start_paragraph": 80, "end_paragraph": 108, "mode": "required", "style": "bare"}
  ],
  "exceptions": []
}
```

`optional` 表示该段允许省号，但出现的标号仍查一致性；`exempt` 表示该段的名称不要求尾随标号，整段例外必须有模板或用户依据。标记表前置编号需人工按每个表项核对，不能套用尾随数字检查。例中段号只演示配置形式，实际案件重新提取段落。

输出 JSON 保存每个名称的段落、字符起点、别名、预期与实有标号、上下文及状态；CSV 保存同一逐处表。跨 Word 字号、加粗等 run 的名称仍合并识别。接受态读取新增文字、排除删文，拒绝态反向读取。段落标记修订若留有文字，会列出边界待复核，先用 Word 验证物化结果再用于段落验收。

每条例外使用精确位置，须写明当前词指向何物及依据。

```json
{"paragraph": 88, "name": "安装孔", "start": 146, "reason": "此处属于灯板的安装孔，图9及本句安装关系可核；并非标记表中遮光罩安装孔2326。"}
```

`start` 为所选态段落内从 0 开始的字符位置。每条只豁免该处，修改文字后若坐标失效脚本会中止，要求重新审定。不得为清空异常而对同名词设跨篇豁免。错误未知标号、已知但不匹配的标号和标号格式分别报告；未列入名称字典的部件及图上落点仍须人工核对。

## 交付验收

保存所审稿和改后稿的完整逐处记录。接受态正文与拟定稿一致，拒绝态能还原底稿。最终净稿及修订稿均重跑同一标准，全部候选有处理结论；每条例外和确实缺少图证的部位写明依据。改动处看实际渲染页，连查相同部件在其他位置和图中的名称及标号。报告写清检查了哪些段和图、出现次数和例外次数，局部核查不写成全稿完成。

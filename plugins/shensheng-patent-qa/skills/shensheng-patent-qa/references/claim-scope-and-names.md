# 独权保护层次与特征名称

## 用户已确认的要求与适用范围

用户要求今后独立权利要求必须**上位、简洁、抽象**，不得堆入实施例细节；同一特征在正式稿中前后使用一个名称，不以“上位名称（另一特征名称）”另起别名。本参考是撰写与申晟质检共同使用的细则，其他入口链接这里，不另立相反标准。

机械权项与说明书中的新特征，先交代所属、所在或组成和连接关系，再展开形态、细节、动作及作用；名称出现过或编号能对应，不能代替这一行文要求。

适用于发明、实用新型中实际起草或修改的独权及相应保护构思。产品按必要构成与结构关系，方法、软件按其必要步骤、数据或协作关系落实；不把机械件号或形状要求套给其他客体。外观设计没有这类独权，不套本流程。申请后仍须遵守原始记载、程序阶段和允许修改边界，“上位”不授权突破这些边界或无条件扩大已授权范围。

## 这次失误揭示的判断错误

- 把“材料有记载、能解释作用、属于检索区别”当成独权必须保留的理由，没有继续判断该具体形式是否必要。
- 为保留所有效果，将可以分层的多个改进支线取并集，独权变成实施例清单；只删除少量尺寸或换成“组件”名称仍未解决层次问题。
- 质检证明了支持、标号和版式，却没有独立核用户要求的保护层次，仍给出整体通过。
- 上位后未同步主方案、摘要、结尾和名称表，或用括号保留另一名称，使具体实施方式反向缩限或混淆主方案。
- 只查名称及标号是否出现，没有回到首次引入句核所属、设置关系和实际引用链，误把“有先行词”当作结构已经交代清楚。

## 起草时怎样取舍

1. **先确定总体技术构思。** 用一句话写清要保护的核心问题及必要配合，再组织独权。整机模块树和全部有益效果是披露组织依据，不自动成为独权的组成清单。确实不可分的多机构协同可以保留；不能机械限定为一个部件、一种机构或一条动作链。
2. **逐限定作真实删除和替代检验。** 在已有计划或底稿记录“具体限定—核心作用—删除/替换后是否仍成立—保留/上位/下沉/删除—材料位置”。检验的是选定核心构思及其核心问题，不是要求一个独权同时解决全文所有问题。材料仅支持某特定必要组合时保留并说明理由，不为短而删掉核心关系。
3. **抽取有依据的共同关系。** 用能识别技术对象的上位名称及必要连接、位置、运动、约束或处理关系表达。仅把零件改名“组件/模块”而保留全部具体构造，不算上位；仅写“实现可靠动作/提高效率”等结果，缺必要技术关系，也不合格。用于检验的假设替代不自动成为新实施例，不能凭上位词补造磁吸、电控等案外事实。
4. **把后备分开。** 有独立后备价值的实现方式安排从权，每项简洁写新增限定及必要关系，引用真正提供基础的权项。不要把旧独权整段搬入一条从权。尺寸、数量、形状、驱动、导向、紧固、材料和安装细节逐案判断，非必要者留从权或实施方式；某一具体形式确属核心时不一概删除。
5. **检索范围与保护层次分别判断。** 区别特征编号和数量仅用于证据映射，不决定独权限定的条数或具体措辞。不能把多篇文献的全部区别拼入独权以求稳妥。按实际概括后的组合评价；有实质风险时，定位有据且必要的限定或后备组合，并记录范围影响。既不能用下位从权补足独权未限定的内容，也不能以写作简洁为由放过已确认的新颖性、创造性或支持问题。范围改变后按受影响部分补检，不沿用旧长独权的结论冒充新范围已核。

## 同一特征只用一个正式名称

- 在本案术语表确定正式名称和编号后，权项、主方案、具体实施方式、摘要、附图说明及标记表按相应栏目统一。上位命名后同步全稿，不在后文交替使用旧具体名称，也不写“名称甲（名称乙）”“名称甲又称名称乙”来保留第二个正式名。
- 需要说明具体形态时，继续使用同一个名称并写构造，例如“承托件呈杯状且设有承托凹部”“传动部径向凸出”“开闭件沿盖板平移”。这类形态描述不另设特征名，不因机检而硬加一个别名或虚拟编号。
- 此项针对特征命名，保留权项的数字标号括号、正常解释、公式及必要的文献原文引用。同一组件与其真实子部件确实是不同层级时，分别命名并核实际归属，不能为统一词面把不同实体合并。
- 读取历史材料时可用旧名和别名定位、追溯；正式稿验收时，同号不代表允许异名。命名扫描应把已知旧名作为候选错误识别，而非自动豁免；结构类型和原文引用等非命名用途逐处核实，未知别名仍须人工通读。

## 新特征先交代归属和设置关系

机械权利要求和说明书首次介绍部件或子特征时，先使读者知道它属于谁、设置在哪里，或怎样与已经引入的部件连接，再说明自身形态、内部构造、配合、动作和作用。可采用有材料支持的“A包括B”“A上设有B”“B安装于A”“B连接于A”等表述。引入关系与进一步限定可以在同一句中连续完成，不强制拆成两句或每句重复“包括”。已有清楚引入时自然回指，不重复列组成。

未与已有结构接上时，不直接从新特征的形态、动作或效果开讲。“A的B”在作用句中临时出现，也须核实是否已说明B的所属或设置关系；仅有名称定语、图例名称或附图标记，不能自动判为引入完整。位置和连接按实际对象写明，不为行文完整补造安装、固定或传动关系。

权项按本项前文及真正继承的引用链核查。从属项可以首次增加新部件，但须将它接到本项已经引入或由实际引用链继承的结构。平行从权、后续权项、说明书或标记表中出现过的名称，不能替代当前权项的结构引入；调整引用项时另核累计限定及保护层次。说明书各技术方案与实施方式按自身实际展开顺序核查，不因权项或图例列过名称就跳过正文介绍。

从整机到模块、子部件逐层展开，随所述结构引入相应特征，不要求在开头一次列出全部零件。独权仍只写必要核心构成与关系；不能为介绍层次而把所有从权或实施例细节上提。正式名称、各栏目部件标记政策继续执行，实用新型内容省标记不省技术关系。本节的安装、位置写法用于机械结构，方法及软件按实际对象的定义和关系组织，不硬套机械组成。

独立复核沿“首次引入句—已引入的母件或真实继承链—所属/位置/连接—后续展开”核实际文字，在现有底稿或审核记录中定位原句；对缺失项记录依据、修改及复核结果。首次出现位置、名称次数、标号一致或正则检查只可辅助定位，不能代替这一语义判断，也不能用笼统的“先行基础已核”销项。

## 配对关系、量词与配合对象

- 同句涉及两条或多条传递、对位或连接支路时，逐条写清起点、经过对象与终点。用“分别经A和B到达C和D”之前核实配对是否唯一；容易读成任意组合时，改为“A到达C，B到达D”等显式关系。只增加“分别”不能消除原有配对歧义，也不为句式对称增加材料未公开的独立光源、通道或控制关系。
- “至少一部分”“至少部分”“各”“每组”须有明确的限定对象、数量范围和技术目的。区分整件与功能区域、组内部分与每组均有部分；逐处判断是否确有必要，不作通用扩张词机械添加。整件具有某功能不等于整件所有区域均参与该配合，只有部分参与也不推出余部必须具有相反性质。可用“功能部由构件形成”清楚说明关系时，不为保留量词增加不必要解释；确有范围区别时保留并在说明书交代依据。
- 端部、方向和代词按实际对象命名。多个对象或多条方向已在句中出现时，用相应名称替换无法唯一回指的“前两者”“其”“另一端”等；已有清楚、唯一回指时可自然使用，不机械重复冗长名称。涉及安装柱及孔等母子关系时，沿上一节先引入母件及其所在，再介绍孔和紧固关系。
- 以组件或单侧产品为保护对象时，先介绍本侧结构，再以有依据的“用于与外部部件……配合”限定用途或接口。不能因叙述装配过程就把外部整机、另一侧组件或另一侧结构写成本侧的组成。材料确实支持的本侧形状、设置及配合关系仍应写清；也不能凭用途用语补造本侧结构。
- 从权简洁性继续按后备价值判断。常规孔、让位及安装细节并非看到相应零件就自动视为已公开，也不必一律单列从权。回查实际连接和可实施教导，非本条技术点且无独立后备价值的细节留在说明书；确有必要或后备价值的保留。删除后连查引用链、技术支持和保护对象。

## 删除特征或标记后的全套同步

用户要求删除某个附图标记时，先分清是仅撤去数字与引线，还是同时删除技术特征。仅撤标记不自动删除仍需披露的技术关系；删除从权也不自动删去有支持价值的实施例。按核定操作同步全文每次出现、标记表、说明书附图、摘要附图、Word嵌图及独立PDF，并从实际成品反查，不以只改图例或某一幅图代替整套处理。

新增标记按真实可辨的整体或子部落点布设。已有下位子号不能自动替代所要求的整体标记；沿用本案编号并核图中实际显示、同号归属和相邻线条。删除或新增记录到图页及每次出现，保留没有改变的技术披露与几何，不因标号操作改出新的结构事实。

## 实用新型内容章节不带部件附图标记

用户要求实用新型说明书的“实用新型内容”章节中，技术特征只用统一正式名称叙述，不附部件标记；名称后的裸数字和括号数字均不保留。该要求按实际栏目起止范围执行，不扩大到权利要求、具体实施方式或附图标记表，也不自动套用其他申请类型的栏目。其他栏目仍按各自核定格式核号。

省去的是部件附图标记，不是“图n”引用、段落编号、权项回引序号、尺寸、数量、数值范围或公式。名称和技术关系继续与全稿一致，不能因本章不显示编号就另起名称或删去必要关系。改稿前后核正文及最终Word、PDF，不能用正则删除所有数字或括号。

质检配置按实际段落边界对本章采用`mode: forbidden`：检查部件名后不出现附图标记，同时保持`require_canonical_names: true`。这与可省可带的`exempt`不同；需要标记的具体实施方式仍用其`required`规则。不得跳过本章名称核查、在全篇关闭标号检查，或为消除“漏号”提示重新补入本章标记。

## 成稿、质检与放行

撰写者同步主方案、从权顺序、效果、摘要、术语表和结尾。主方案不能仍以“必须采用某具体形式”锁住已上位的独权；实施例保留足够的真实构造与动作教导，不因独权简洁而删薄披露。

独立审阅者先从用户要求及原材料核定标准，再独立复读每个独权的核心构思和逐限定取舍。单独记录**保护层次、技术支持、特征引入与归属、特征名称、标号/图面、实际成品**的结论及依据；保护层次未核、仍堆非必要细节、只有结果功能、新特征缺少引入关系或名称未统一时，不得以其他项通过放行。字数、页数和权项数只能作提醒，不能作为通过阈值；生成报告本身也不是通过证据。

用户再次指出同类错误时，对应旧通过结论失效，按本轮授权重核；文件摘要未变也不能沿用被质疑的判断。普通有据纠偏在既有授权内完成，不为表格或流程新增确认。确有无法确定的实质取舍或申请后依据缺口时，说明影响并继续其他可做部分，不靠堆细节销项。

## 与其他技能的职责边界

| 既有要求 | 本规则的衔接 |
| --- | --- |
| 交底、说明书完整披露，按整机和模块展开 | 保留实施深度；不要求所有模块和效果进入独权。 |
| 真实制造、加工、装配及工况验收 | 保留模型与实施例的细节；不反推每个倒角、螺钉都属独权必要限定。 |
| 按整机和模块展开、先行基础核查 | 新特征先接上所属或设置关系再展开；同句可完成引入，不把全部子件上提独权。 |
| 特征完整标号、真实图面及逐处名称检查 | 按各栏目核号；实用新型内容按本节要求省去部件标记并查残留，名称仍逐处核。不为凑全标号把图上所有零件补进独权；同号异名仍须统一。 |
| 检索、OA及独立审稿的范围备选 | 适用实际阶段与用户方向；不自动将全部区别上提，不机械凑多档改法，也不忽略有据的风险。 |

## 脱敏语义回归

以下是判断练习，不是固定字数测试，也不要求逐案额外生成一份模板：

| 合成情形 | 应有判断 |
| --- | --- |
| 主权把核心传动与可独立取舍的照明、运输、防尘支线全写入，仅说明各自有用 | 重新划分层次，不能据有用就判必要。 |
| 具体螺杆改名“驱动组件”，仍保留所有螺纹、座及紧固细节 | 检查假上位，不能仅凭换名放行。 |
| 为缩短只剩“驱动组件实现可靠夹紧” | 必要技术关系缺失，不能用结果代替结构。 |
| 材料仅支持两配合共同成立，删任一即失去核心作用 | 可以保留有据细节，不能为短而删。 |
| 各篇检索文献的区别取并集后全塞主权 | 回到核心构思及当前概括范围，不自动放行。 |
| 支持、标号和版式全通过，保护层次尚未独立核读 | 不能概括为整稿合格。 |
| 主权上位，主方案、摘要或尾段仍强制具体实现 | 同步未完成。 |
| 图例写“承托件（托杯）”，后文同号交替使用两名 | 正式名称未统一；改同名构造描述，保留正常数字括号。 |
| 图例列有锁杆，正文首句直接写锁杆随手柄动作，未交代锁杆属于哪一结构 | 回查材料，先补有据的组成或设置关系，再解释动作；不能据图例或标号放行。 |
| 权项3首次设导向套，权项4只引用权项1却直接展开该导向套 | 按真实引用链检查；本项有据引入或调整实际依附关系，并核范围影响，不从平行项借基础。 |
| “支架上设有可滑动的夹持块，夹持块……”在同句接着限定形态 | 已完成所属及可动关系引入，无须机械拆句或重复列全部组成。 |
| 实用新型内容无部件标记，实施方式按既定格式带号，本章仍有图2及尺寸描述 | 按栏目分别检查，不给内容章补号；保留图号和技术数值，异名仍须检出。 |
| 两条流路写成“分别经入口甲和入口乙通向腔甲和腔乙”，读者无法确认一一配对 | 从原材料核对后逐条写明入口与腔的关系，不凭并列顺序认定配对。 |
| 整片透明盖板有安装边，只有开口对应区承担出光功能 | 区分构件与功能区；“部分”须服务于该关系，不推出安装边必然不透明，也不机械要求全部区域工作。 |
| “两组中的至少部分单元”改成“每组均有至少部分单元” | 先核两组是否均有该关系；后一句增加每组数量要求，不能只当语序润色。 |
| 单侧连接器权项介绍了另一侧壳体、盖板及端子作为自己的组成 | 核保护对象及真实所属，本侧先引入，再写有据的外部配合用途；不能只换称谓而保留错误组成。 |
| 用户只要求去掉某数字，正文、摘要图或Word嵌图仍留同号 | 按每次出现定位并同步实际副本；技术关系是否保留另作判断。 |
| CAD需要完整紧固件，或标号台账列了全部零件 | 不能推出独权也必须列全。 |

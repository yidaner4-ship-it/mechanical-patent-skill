# 审核报告与复核记录

默认交付可离线阅读的 Markdown 审核报告。内部逐处数据可用 JSON、CSV 保存，不与洁净交付副本混装。已有可用上游报告组件时可复用生成 HTML，不要求使用者为核心质检另装组件；HTML 无法生成不妨碍交付相同实质内容的 Markdown。改变报告形式不能改变证据或审核结论。

## 报告最小结构

### 结论与范围

- 当前结论：说明已完成的实际检查、影响交付的遗留问题与下一步，不仅填写“通过”。
- 有效版本：申请类型、程序阶段、保护对象、用户指定修改范围。
- 文件清单：审阅文件名及 SHA-256、整改后文件名及 SHA-256；最终交付摘要值以隐私清理后的实际副本为准。报告中不暴露本机绝对路径或身份记录。
- 独立性：独立审阅已完成、仅本地自检或部分完成，说明实际条件。必要的用户确认以内容来源记录，避免带入账号与身份元数据。

### 覆盖台账

| 对象 | 计划范围 | 实际已核 | 未核及原因 | 对应记录 |
| --- | --- | --- | --- | --- |
| 权项及引用路径 | 按实际项号列范围，独权单列 | 项号及已展开路径 | 具体项号、缺少依据或条件 | 权项支持及因果记录 |
| 说明书、摘要与正式栏目 | 段落及栏目范围 | 实际范围 | 具体段或栏目 | 正文记录 |
| 名称与标号 | 字典范围、栏目规则 | 逐处数量和人工补核范围 | 字典外或无法判定的用法 | JSON、CSV 或同字段表 |
| 附图 | 图号、页及各图标记次数 | 已目视图和标记次数 | 具体图、标记与原因 | 逐图逐根表 |
| 交付副本 | 合册、分册、独立 PDF 等实际文件 | 实际打开、渲染与隐私检查 | 未生成或未验部分 | 最终文件清单 |

数量给出统计口径和计数单位。名称总出现数、按栏目要求核号的次数、允许省号次数、逐处核定例外次数及未决次数分别记录，避免重复计数。图号数量与标记出现次数分别统计。自动脚本处理的全部配置词，不等于全文全部名称已经人工核清。

### 权项支持与因果

每项记录项号、引用路径与累计限定、原文特征、说明书和图证位置、支持判定及缺口。每个独立方案另记问题及原因、作用关系、成立工况、直接效果和依据；保护层次及逐限定取舍按[共同细则](claim-scope-and-names.md)单列，正式名称一致性与数字格式分别记录。未执行检索时明确登记，检索状态与稿内审查状态分开。

### 意见与处理

每条意见至少包含以下字段：

| 字段 | 内容 |
| --- | --- |
| 稳定编号及优先程度 | 同一问题返稿沿用编号 |
| 原件位置与证据 | 文件、页／项／段／图、标号，必要的原句或可见部位 |
| 判断及依据 | 问题是什么，影响哪个方案、解释或交付位置；区分事实、推断及待确认 |
| 建议与同步位置 | 适用本轮的改法及应连查对象，不凭空补造结构 |
| 处理 | 已采纳、待确认、已驳回或已解决，并附理由或实际修改位置 |
| 复核 | 复核文件摘要值、实际结果和遗留影响；无事实或图证的不能仅凭改字关项 |

逐处例外记录段落、字符位置、原名称、应有及实有标号、当前所指对象和依据。图面表按“图号与一次标记出现”一行，记录目标、落点证据、同号跨图关系、引线与邻线结果及关联意见号。正文覆盖表记录本段所引各图如何支持标号及配合关系。

### 最终状态与未核项

技术审阅、独立性、名称机检、人工名称核对、实际目视核图、整改复核、报告生成、隐私清理分别记已完成、部分完成、未完成或不适用；不适用须说明理由。扫描器无异常、报告成功生成或文件能打开，均不能替代其他项目通过。

列出全部剩余问题及未核位置、缺少什么、影响什么和建议补充。已解决、已驳回、待确认分别汇总，汇总数由逐项记录核算。只有实际覆盖和复核记录支持时才能写“全稿逐处核对完成”；有未核图、未决关键关系或缺少独立执行条件时，结论如实保留范围。

正式交付前再次核对报告对应的最终文件摘要值、必要链接及可读性，清除报告和附件内不属于交付内容的身份、账号、工具标记、隐藏路径与元数据。需要保留原生修订或批注时保留功能并匿名化身份；内部审核日志和版本底稿另存。
